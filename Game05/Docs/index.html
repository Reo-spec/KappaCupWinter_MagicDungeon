k2Engine / C++ / DirectX 12

ドキュメント

河原学園内製のゲームエンジン k2Engine の学習教材と、 エンジンに組み込まれたデバッグ機能の説明です。

文書内容
教材 目次 未経験から始める学習コース（LV1〜LV5、全92章）
デバッグGUI と GOHandle エンジンに組み込まれたデバッグ機能の使い方
素材の用意のしかた 画像・音・エフェクトの探し方、変換、ライセンスの注意
章のひな形 教材を書く人向けのテンプレート
エンジン改造の内容とマージの手引き エンジンに入れた変更の一覧。レビューする人向け

エンジン本体の解説は、リポジトリ直下の K2Engineについて.pdf にあります。

01はじめての人へ

  1. 教材 目次 を開く
  2. LV1-01 環境構築とビルド から始める
  3. 自分のGitリポジトリを作って、毎章コミットする
同じゲームを3回作り直します LV2で作ったシューティングを、LV3で3D化し、LV4で設計し直し、LV5で速くします。 だから、自分の書いたコードは必ず残しておいてください。

02完成形のサンプル

行き詰まったときのために、各LVの到達点をそのまま動く形で Sample/ に置いてあります。 先に見てしまっても構いません。 それぞれの readme.txt に「読む順番」が書いてあります。

フォルダ到達点中身
