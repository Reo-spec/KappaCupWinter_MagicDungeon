# MagicDungeon ゲーム仕様

企画書（作者が手元で管理している PDF）の要点をまとめたもの。仕様が変わったらこのファイルを更新する。
「(仮)」が付いた数値と「未定」の項目は、確定するまで勝手に決めない。

## 概要

- ジャンル：三人称視点のアクションシューティング（一人用、PC）
- あらすじ：普通の少年が森で迷い込んだダンジョンで、探索と敵を倒すことを繰り返して魔法を集め、最後にボスを倒して脱出する
- ステージ：迷路の探索層 → ボスステージ（壁のない大広間で動き回って戦う）
- 小目的：迷路のゴールを目指す、宝箱を開けて使える魔法を増やす
- 大目的：集めた魔法でボスを倒す

## ゲームの流れ

- **スタート**：最初は魔法を 1 つも持っていない。スタート地点に、チュートリアルを兼ねた宝箱があり、中に石の魔法が入っている（2026-11-04 に決定。この宝箱は場所を固定し、ランダムの抽選に入れない）。ほかの魔法も宝箱から手に入れる
  - 周りはほとんど真っ暗。石の魔法の宝箱の近くに、「持ち歩けるたいまつ」が入った宝箱もある（2026-11-04 に決定。この宝箱も場所を固定し、抽選に入れない）
- **プレイ中**：探索 → 宝箱を開ける → 敵を倒す、を繰り返す。探索がメイン
- **クリア**：ボスを倒してダンジョンから脱出
- **ゲームオーバー**：プレイヤーが死ぬ（HP が 0 になる）と、スタート画面ではなく**迷路のスタート地点**に戻される。手に入れた魔法やアイテムは失わない（2026-11-04 に決定）
  - 戻されると、**最大 HP が半分**になる（2026-11-04 に決定）。何度も死んだときにさらに半分になるか、下限があるかは**未定**
  - 減った最大 HP は、宝箱から手に入るアイテムで元に戻せる（2026-11-04 に決定）。1 個でどれだけ戻るかは**未定**
  - 開けた宝箱は、開いたままになる。倒した敵は復活する（2026-11-04 に決定）
- **ボスステージへの移行**：迷路のゴールにたどり着いたら、ボスステージに移る

## 迷路（洞窟迷路）

- スタート地点のまわり（石の魔法とたいまつの宝箱がある所）は、いつも同じ形で、ランダムにしない。ランダムなのはそこから先（2026-11-04 に決定）
  - ここは部屋ではなく通路にする（2026-11-04 に決定）
  - 通路の宝箱は、スタート地点から見て、たいまつの宝箱が手前、石の魔法の宝箱が奥（2026-11-04 に決定）
  - 通路の形：スタートから上へ進み、角で曲がって横に長い通路（9 マスくらい）を進み、もう一度曲がって迷路に入る。2 つの角の「まっすぐ先」が行き止まりの出っ張りになっていて、そこに宝箱を置く（2026-11-04 に決定）
  - 迷路に入ってすぐの所で、道が 3 方向に分かれる（2026-11-04 に決定）
- 敵は、石の魔法とたいまつの宝箱を 2 つとも開けてから出てくる（2026-11-04 に決定）
  - 宝箱を開けずに通路の先（迷路）へ入ったときも、そこで敵が出てくる（2026-11-04 に決定）。宝箱は通路に残っているので、あとから戻って開けられる
- その先の迷路の形は、用意した 5 つ (仮) の中からランダムに選ぶ。完全ランダムにはしない（バグを再現できるようにするため。2026-11-04 に決定）
- 迷路の形は固定のまま、中身（宝箱・敵・開け閉めする扉の場所）をランダムにする（2026-11-04 に決定）。扉がランダムでも、スタートからゴールまでの道は必ずある
- 迷路はゲームを始めたときに 1 回だけ決まり、そのプレイの間はずっと同じ。プレイヤーは選べない。死んでスタート地点に戻っても、迷路は変わらない（2026-11-04 に決定）
- ランダムにするのは β版から。α版では迷路を 1 つにする
- α版の迷路の宝箱は、炎の魔法が入ったもの 1 つだけにする（2026-11-04 に決定。今のコードにある魔法が石と炎だけのため）。レベルアップはまだ入れない
- β版以降で、宝箱から出る 6 種類の魔法（炎・氷・雷・闇・回復・ゴースト）を手に入れられるようにする。レベルを上げる分の宝箱もそのときに考える
- 迷路は大きめにする（2026-11-04 に決定）。α版の迷路は 31×31 マス（下にスタート通路）。1 マスの大きさは 400 (仮) で、実際に歩いてから調整する（2026-11-05 に決定）
- 迷路の中に、ぐるっと回れる「逃げ道の輪」を作る。敵に追われて行き止まりに追いつめられないようにするため（2026-11-05 に決定）
- 壁の見た目は、ダンジョンらしい石の壁にする（2026-11-05 に決定）
- 迷路には天井を付けて、洞窟のダンジョンらしくする（2026-11-05 に決定）。壁の高さは**未定**
- 扉・宝箱・敵の数は**未定**

### 宝箱（2026-11-09 に決定）

- 開け方：宝箱に近づいて、ボタンを押すと開く。どのボタンか・どれだけ近づけばよいかは**未定**
- 中の魔法は、魔法のスロットのうち、空いている（`None` の）一番前に入る
- 手に入れた魔法は、スロットとは別に「持っている魔法の一覧」に全部覚えておく。スロットが埋まっていても、魔法は消えない（2026-11-10 に決定）
- スロットが 3 つとも埋まっているときにどうするかは、β版で魔法を入れ替える動作を作るときに決める（**未定**）
- 同じ魔法を 2 回以上手に入れたときは、β版のレベルアップに使う（2026-11-10 に決定）。α版では、同じ魔法を何個持っているかを確かめられる仕組みを MagicManager に作っておく（2026-11-10 に決定）
- 宝箱のモデルは、以前使ったものを整えて使う
- α版のたいまつの宝箱は、置くだけで中身はない。開けたらログを出すだけにする（たいまつの光は後で作る。2026-11-09 に決定）

### α版の迷路（2026-11-05 に決定）

1 文字が 1 マス。`#` 壁、`.` 床、`S` スタート、`L` たいまつの宝箱、`M` 石の魔法の宝箱、`F` 炎の宝箱、`T` 宝箱の候補（β版用）、`E` 敵の候補、`G` ゴール（上の外壁の出口）、`O` 逃げ道の輪を作るためにあけた壁（床として扱う）。

## 魔法

初期攻撃の石に加えて、魔法を 7 種類実装する予定。

| 名前 | コード上の名前 | 効果 |
|---|---|---|
| 石 | Stone | 初期攻撃 |
| 炎 | Fire | 基本ダメージ＋時間ごとの追加ダメージ（燃焼） |
| 氷 | Ice | 基本ダメージ＋相手の移動速度を下げる |
| 雷 | Thunder | 基本ダメージ。クールダウンがほかの魔法より少し短い |
| 闇 | Dark | 基本ダメージ＋追加ダメージ（基本ダメージの 0.7 倍）。クールダウンがほかの魔法より少し長い |
| 回復 | Heal | HP を回復する（回復量は**未定**） |
| ゴースト | Ghost | 数秒間、敵に見つからなくなる。宝箱から低い確率で出るか、鍵付きの宝箱から出る |
| 敵魔法 | Enemy | 通常の魔法より攻撃力が高い。タイミングよく入力すると 3 回連続で出せる |

- 宝箱から同じ魔法が出たらレベルが上がる（最大 Lv3 (仮)）。敵魔法にはレベルがない
- 魔法の見た目は、β版ですべてエフェクトにする予定（2026-11-10 に決定）。α版は仮のモデル（`kariFireMagic.tkm`）のまま
- 燃焼中にもう一度炎の魔法が当たったら、燃える時間を最初からやり直す（上書き）。足したり、無視したりはしない
- 敵を 5 体 (仮) 倒すごとに、クールダウンが少し短くなる
- たくさん敵を倒すと、その敵の属性の魔法（敵魔法）が使えるようになる

## 敵

| 名前 | コード上の名前 | 攻撃 |
|---|---|---|
| 炎の敵 | Fire | 炎の魔法を撃ってくる |

- 敵は全員、魔法で攻撃する（属性ごとの魔法。2026-10-28 に決定）
- 炎の敵の魔法が当たると、プレイヤーも燃焼ダメージを受ける
- 敵の種類ごとに動き方を変える予定。属性と動き方は1対1（2026-10-29 に決定。それぞれの動き方は**未定**）
- ほかの属性の敵は**未定**

## UI

- 左上：プレイヤーの HP バー
- 左下：魔法選択リング。魔法が 3 つ並んでいて、左右の入力で回して選ぶ。上に選んでいる魔法の名前、それぞれのアイコンにクールダウンの残り秒数を表示する
- 画面中央：照準
- 敵の頭上：敵の HP バー
