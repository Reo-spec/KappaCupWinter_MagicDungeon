# オブジェクトプールで弾を飛ばす

- **開始**：2026-10-23
- **状態**：完了（その後、プールはやめた）
- **段階**：プールに戻す話は3回目（設計）まで
- **関連**：コミット `346983e`（プールが動いていた時点のコード）

## 内容

ビルドエラーの解消 → Game から管理役 → プール → 魔法への Update / Render の中継 → 位置と向きのセッター → モデルへの反映 → 速度の設定、まで作って弾が飛んだ。「時間が来たらプールに戻す」の設計中に、プール自体をやめることにした。

## 分かったこと

- `C` で始まるエラーはコンパイル、`LNK` で始まるエラーはリンク。LNK2019 は「宣言はあるのに定義がない」
- エンジンが `Update` / `Render` を呼ぶのは `NewGO` したものだけ
- `rc` は受け取った関数の中でしか使えない。「自分と同じ名前の関数を、下の人に呼ぶ」
- `ModelRender` の `SetPosition` → `Update` は位置の反映、`Draw` は描画。役割が違う
- 早めに抜ける `if` は「ダメなとき」を条件に書く（`== nullptr` なら `return`）
