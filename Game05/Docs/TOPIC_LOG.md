# 話題の記録

Claude と話した話題（質問・問題・相談）を、**話題ごとに1ファイル**で `Game05/Docs/topics/` に記録する。
会話が変わっても続きから再開できるように、学習モードの「何回目の質問か」も話題のファイルで管理する。
このファイルは目次。

## 今の話題

- [魔法選択UIと撃つ魔法の紐づけ](topics/2026-10-24_magic-select-link.md)

## 話題の切り替え

- ユーザーが `/next` と打ったら、今の話題を閉じて、新しい話題のファイルを作る（手順は `.claude/commands/next.md`）
- 新しい話題は、学習モードの段階を **1回目から**数える

## 話題のファイルの書き方

- ファイル名：`topics/YYYY-MM-DD_英語の短い名前.md`（日本語は使わない）
- 先頭の項目
  - **開始**：話題を始めた日
  - **状態**：進行中 / 完了 / 保留
  - **段階**：学習モードで今何回目か（1回目：ヒント / 2回目：説明 / 3回目：個別指導 / 4回目：答え）。コードの話でなければ「—」
  - **関連**：ファイル、コミット、Notion のタスク
- 本文：「内容」（何の話か、今どこまで進んだか）、「分かったこと」（次に同じ問題に出会ったときに役立つ要点）、必要なら「残っていること」
