GUIまず絵をいじってみる

難易度 ／ 前提 2-24

LV3 へようこそ ここからは「どうすれば良く見えるか」を扱います。
いきなりシェーダのコードは書きません。 まずスライダーを動かして、この値をいじると絵がこう変わるを 体で覚えてから、その中身を開けます。

01この章でできるようになること

  • ライトとポストエフェクトを、実行しながら調整できる
  • それぞれの値が絵のどこに効くかを、自分の目で確かめられる
  • 調整した結果を保存できる

02準備 ― 3Dのものを出す

ライトの効果は、2Dのスプライトには出ません。 3Dモデルを1つ出しておいてください。 

// Game.h
private:
    ModelRender m_modelRender;

// Game.cpp
bool Game::Start()
{
    m_modelRender.Init("Assets/modelData/unityChan.tkm");
    return true;
}
void Game::Update()  { m_modelRender.Update(); }
void Game::Render(RenderContext& rc) { m_modelRender.Draw(rc); }

くわしくは 3-09 でやります。 いまはコピーして動かすだけで構いません。

03Light パネル

F1 → Graphics → Light を開きます。

項目意味
ambient 環境光。どこからともなく当たっている光。 影の中の明るさがこれで決まる
direction 光が進んでいく向き。 {0, -1, 0} なら真上から真下
color 光の色と強さ。1.0 より大きい値も入れられる
cast shadow このライトで影を落とすか

やってみよう

  • ambient を真っ黒にする。 影の中が完全に見えなくなる
  • direction の Y を 0 に近づける。 夕方のような、横からの長い影になる
  • color を 3.0 まで上げる。 白く飛んで、あとで出てくるブルームがはっきり出る
  • ライト1〜3 の color を上げて、色違いの光を当てる
direction は「向き」であって「位置」ではありません ディレクショナルライトは太陽のイメージです。 無限に遠くにあるので、位置は関係なく、向きだけがあります。
位置のある光（電球のようなもの）は 3-11 でやります。

04Post Effect パネル

F1 → Graphics → Post Effect。

ポストエフェクトとは、 3Dを描き終わったあとの「絵」に対して、あとからかける加工のことです。 写真の加工アプリと同じで、描いたあとの画像をいじっています。

効果何をしている切るとどうなる
Bloom 明るい部分をにじませる 光っているものが、ただの白い面になる
Tone map 明るさを画面に出せる範囲に収める 明るいところが真っ白につぶれる
FXAA 輪郭のギザギザをなめらかにする 斜めの線がギザギザになる
Depth of field ピントの外をぼかす 全部くっきりする
SSR 床などへの映り込み 映り込みが消える

やってみよう

  • Tone map を切る。 明るいところが真っ白につぶれる。いちばん違いが分かります
  • Bloom の threshold を 0 に近づける。 画面全体がぼんやり光る
  • FXAA を切って、輪郭を拡大して見る。 ギザギザが見える
  • Tone map の middle gray を動かす。 カメラの露出のように、全体の明るさが変わる

05調整した値を保存する

どちらのパネルにも、いちばん下に Save / Load があります。 押すと Assets/settings/renderSettings.txt に保存されます。 

light.directional.0.direction  = 0.5774 -0.5774 -0.5774
light.directional.0.color      = 1.2000 1.2000 1.2000
light.ambient                  = 0.1000 0.1000 0.1000
postEffect.bloom.threshold     = 1.0000

ただのテキストなので、メモ帳で直接編集できます。

ゲーム開始時に反映したいときは、 自分のライト設定を書いたあとに読み込んでください。 

bool Game::Start()
{
    // ...自分のライト設定...

    nsDbg::LoadRenderSettings();     // デバッグGUIで調整した設定を反映
    return true;
}

06演習

演習1（まねる）

3Dモデルを1体出して、Light と Post Effect のパネルを開き、上の「やってみよう」を全部試す。

演習2（絵を作る）

「夕方」「夜」「真昼」の3つの雰囲気を、パネルの操作だけで作る。それぞれ Save して、ファイルを見比べる。

解答例を見る（まず自分でやってから）

参考の値です。正解ではありません。自分の目で決めてください。

directioncolorambient
真昼0.0, -1.0, -0.21.2, 1.2, 1.2（白）0.35, 0.38, 0.45（やや青）
夕方-0.9, -0.25, -0.31.8, 0.9, 0.5（オレンジ）0.25, 0.15, 0.20（紫がかる）
夜0.2, -0.7, -0.50.25, 0.30, 0.55（青白い）0.05, 0.06, 0.12（暗い青）

コツ

  • 夕方は「光の向きを寝かせる」のがいちばん効きます。 Yを0に近づけると影が長く伸びて、一気に夕方らしくなります
  • ambient に色を付けると雰囲気が出ます。 影の中が真っ黒だと不自然です。夜なら青、夕方なら紫を少し混ぜる
  • 夜は middle gray を上げると、暗いのに見やすくなります
この作業を「ライティング」と呼びます モデルもテクスチャも変えていないのに、まったく違う絵になったはずです。 ゲームの見た目は、モデルの出来よりライティングで決まる部分が大きいのです。

演習3（調べる）

Tone map を切ると、なぜ真っ白につぶれるのでしょうか。color を 3.0 にしたときのことを思い出しながら考えてみる。

解答例を見る（まず自分でやってから）

画面が表示できる明るさは 0.0 〜 1.0 です。 それより明るい値は、全部 1.0（真っ白）になります。

ところが、ライトの color は 3.0 でも 10.0 でも設定できます。 太陽の明るさと、部屋の電球の明るさは、実際には何百倍も違うからです。

この「画面に出せる範囲を超えた明るさ」を扱う仕組みを HDR（ハイダイナミックレンジ）と呼びます。

やっていること
3Dの描画中明るさの制限なしで計算する（3.0 でも 100.0 でもOK）
Tone mapそれを 0〜1 に「いい感じに」押し込める
画面0〜1 の範囲で表示

Tone map を切ると、この「押し込める」処理が無くなります。 1.0 を超えた部分は、全部そのまま真っ白になります。

middle gray は、「どのくらいの明るさを中間の灰色とみなすか」 という基準です。カメラの露出と同じで、 小さくすると全体が暗く、大きくすると明るくなります。
