01この章でできるようになること

  • ボタンとスティックの入力を読める
  • 「押した瞬間」と「押しっぱなし」を使い分けられる
  • パッドが無くてもキーボードで動かせることを知っている

02基本の書き方

入力は g_pad[0] から読みます。[0] は1Pのことです。 （4人まで g_pad[0] 〜 g_pad[3] が使えます） 

void Player::Update()
{
    // 押した瞬間だけ true
    if (g_pad[0]->IsTrigger(enButtonA)) {
        Jump();
    }

    // 押している間ずっと true
    if (g_pad[0]->IsPress(enButtonB)) {
        Shoot();
    }

    // スティックは -1.0 〜 1.0
    float x = g_pad[0]->GetLStickXF();
    float y = g_pad[0]->GetLStickYF();
}

03IsTrigger と IsPress の違い

ここを間違えると、必ずおかしな動きになります。

関数いつ true使う場面
IsTrigger() 押した瞬間の1フレームだけ ジャンプ、決定、メニューを開く
IsPress() 押している間ずっと 移動、連射、ためる
よくある事故 決定ボタンに IsPress を使うと、 1回押しただけでメニューが何十個も進みます。 （60fpsなら、0.5秒押しただけで30回反応します）
逆に、移動に IsTrigger を使うと、1回しか動きません。

04使えるボタン

定数キーボード（パッドが無いとき）
enButtonUp / Down / Left / Right矢印キー
enButtonA / B / X / YZ / X / C / V など
enButtonStart / enButtonSelectEnter / Space など
enButtonLB1〜LB3 / enButtonRB1〜RB3肩ボタン・トリガー

キーボードの割り当ては環境によって違うことがあります。 自分の環境で実際に押して確かめてください。 パッドをつなぐのがいちばん確実です。

そのほか、こんな関数もあります。

g_pad[0]->IsPressAnyKey();                   // 何か押されている？
g_pad[0]->SetVibration(0.5f, 1.0f);          // 0.5秒ふるえる（強さ0〜1）
g_pad[0]->GetRStickXF();                     // 右スティック

05スティックで動かす

void Player::Update()
{
    const float dt = g_gameTime->GetFrameDeltaTime();
    const float SPEED = 500.0f;    // 1秒で500進む

    float x = g_pad[0]->GetLStickXF();
    float y = g_pad[0]->GetLStickYF();

    m_position.x += x * SPEED * dt;
    m_position.y += y * SPEED * dt;

    m_spriteRender.SetPosition(m_position);
    m_spriteRender.Update();
}

スティックは -1.0 〜 1.0 を返します。 倒していなければ 0 なので、if は要りません。 デルタタイムを掛けるのを忘れないこと（2-02）。

斜めが速くなる問題 上と右を同時に倒すと、まっすぐより 約1.41倍速く動きます。 （三平方の定理です） 気になるなら、移動ベクトルを Normalize() してから速さを掛けてください。 2-15 でベクトルを扱います。

06動かして確かめる

void Game::Update()
{
    if (g_pad[0]->IsTrigger(enButtonA)) {
        OutputDebugStringA("A を押した瞬間\n");
    }
    if (g_pad[0]->IsPress(enButtonA)) {
        OutputDebugStringA("A を押している\n");
    }
}
  • Aを押しっぱなしにすると、「押した瞬間」は1回だけ出る
  • 「押している」は出続ける

07演習

演習1（まねる）

スティックでスプライトを上下左右に動かす。

演習2（違いを見る）

Aボタンを押すたびにカウンタが1増えるようにする。 IsTrigger と IsPress の両方で試して、違いを確かめる。

解答例を見る（まず自分でやってから） 
void Game::Update()
{
    if (g_pad[0]->IsTrigger(enButtonA)) {
        m_triggerCount++;
    }
    if (g_pad[0]->IsPress(enButtonA)) {
        m_pressCount++;
    }

    wchar_t text[256];
    swprintf_s(text, 256, L"Trigger %d / Press %d", m_triggerCount, m_pressCount);
    m_fontRender.SetText(text);
}

結果

  • Aを1回押して離す → Trigger は 1 だけ増える
  • Aを1秒押しっぱなし → Press は 約60 増える

決定ボタンに IsPress を使うと、 0.5秒押しただけでメニューが30個進むのは、この数字のとおりです。

演習3（自分で書く）

Aボタンを長押ししたら強い攻撃、短く押したら弱い攻撃になるようにする。 IsTrigger で押し始めた時刻を覚えて、離したときに判定します。 本文には答えがありません。

解答例を見る（まず自分でやってから） 
// Player.h
private:
    bool  m_isCharging = false;
    float m_chargeTime = 0.0f;
    static const float STRONG_ATTACK_TIME;   // 何秒で強攻撃になるか

// Player.cpp
const float Player::STRONG_ATTACK_TIME = 0.5f;

void Player::UpdateAttack()
{
    const float dt = g_gameTime->GetFrameDeltaTime();

    // 押し始めた
    if (g_pad[0]->IsTrigger(enButtonA)) {
        m_isCharging = true;
        m_chargeTime = 0.0f;
    }

    if (m_isCharging == false) {
        return;
    }
    m_chargeTime += dt;

    // 離した
    if (g_pad[0]->IsPress(enButtonA) == false) {
        if (m_chargeTime >= STRONG_ATTACK_TIME) {
            ShootStrong();
        }
        else {
            ShootWeak();
        }
        m_isCharging = false;
    }
}

ポイント

  • IsTrigger で「押し始め」を捉え、IsPress が false になった瞬間で「離した」を捉える
  • フレーム数ではなく秒で数える（2-02）
  • ためている間、見た目で分かるようにすると親切です。 自機を光らせる、ゲージを出すなど

08確認

  1. ジャンプに使うのは IsTrigger と IsPress のどちら？
  2. スティックの値の範囲は？
  3. スティックの値に何を掛けて位置に足す？
答え
  1. IsTrigger。IsPress だと押している間ずっとジャンプしてしまう。
  2. -1.0 〜 1.0。
  3. 速さ（1秒あたりの距離）とデルタタイム。
