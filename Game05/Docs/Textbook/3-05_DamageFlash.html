02なぜ被弾演出が要るのか

HPの数字が減るだけでは、やられたことに気づけません。 遊ぶ人は自機ではなく、敵や弾を見ているからです。

「当たった」を伝える方法は、いくつも重ねるのが基本です。

03シェーダ

// myCharacter.fx
cbuffer myCb : register(b1){
    float4 param0;       // x = ダメージ演出の強さ（0〜1）
};

float4 PSMain( PSInput In ) : SV_Target0
{
    float4 color = colorTexture.Sample(Sampler, In.uv) * mulColor;

    // 赤に近づける。1.0 で真っ赤。
    color.rgb = lerp(color.rgb, float3(1.0f, 0.2f, 0.2f), param0.x);

    // ついでに少し明るくすると「光った」感じになる
    color.rgb += param0.x * 0.4f;

    return color;
}

04C++側

// Player.h
private:
    MySpriteRender m_spriteRender;
    float m_damageTimer = 0.0f;
    static const float DAMAGE_FLASH_TIME;

// Player.cpp
const float Player::DAMAGE_FLASH_TIME = 0.25f;

void Player::TakeDamage(int damage)
{
    if (m_isInvincible) {
        return;
    }
    m_hp -= damage;
    m_damageTimer = DAMAGE_FLASH_TIME;      // ★ 演出を始める
    PlaySe(enSound_Damage);
}

void Player::Update()
{
    const float dt = g_gameTime->GetFrameDeltaTime();

    if (m_damageTimer > 0.0f) {
        m_damageTimer -= dt;
        if (m_damageTimer < 0.0f) {
            m_damageTimer = 0.0f;
        }
    }
    // 残り時間の割合を、そのまま強さとして渡す（1.0 → 0.0）
    m_spriteRender.SetDamageRate(m_damageTimer / DAMAGE_FLASH_TIME);

    ...
    m_spriteRender.SetPosition(m_position);
    m_spriteRender.Update();
}
「残り時間 ÷ 全体の時間」で 1.0→0.0 が作れます この形は非常によく使います。 フェード、出現、点滅、ノックバック。 全部この「0〜1の進み具合」で書けます。

05点滅させる

じわっと戻るより、チカチカ点滅させたほうが目立ちます。 

// シェーダ側で点滅させる
float blink = abs(sin(param0.y * 40.0f));    // y = 経過時間
color.rgb = lerp(color.rgb, float3(1,0.2f,0.2f), param0.x * blink);

無敵時間中ずっと点滅させるのも定番です。 遊ぶ人に「いまは無敵だ」と伝えられます。

06演習

演習1（まねる）

自機が被弾したときに赤く光るようにする。効果音も一緒に鳴らすと、手応えが大きく変わることを確かめる。

演習2（調整する）

DAMAGE_FLASH_TIME を変えて、いちばん気持ちいい長さを探す。デバッグパネルのスライダーにすると速い。

解答例を見る（まず自分でやってから）

目安は 0.1〜0.3 秒です。

長さ感じ
0.05秒短すぎて気づかない
0.15秒鋭い。シューティング向き
0.5秒もったり。アクションRPG向き
1.0秒長すぎて邪魔
 
m_debugPanel.Register("Game", "Player", [this]() {

演習3（自分で書く）

画面を揺らす演出を作る。（ヒント：カメラか、UIも含めた全部の描画位置を、少しずつランダムにずらす）本文には答えがありません。

解答例を見る（まず自分でやってから）

2Dなら、カメラを動かすのがいちばん簡単です。 

// ScreenShake.h
class ScreenShake : public IGameObject {
public:
    void Start2(float power, float time)     // 揺らし始める
    {
        m_power = power;
        m_timer = time;
        m_totalTime = time;
    }
    void Update() override;
private:
    float m_power = 0.0f;
    float m_timer = 0.0f;
    float m_totalTime = 0.0f;
    Vector3 m_basePosition = Vector3::Zero;
};

void ScreenShake::Update()
{
    if (m_timer <= 0.0f) {
        return;
    }
    m_timer -= g_gameTime->GetFrameDeltaTime();

    // だんだん弱くする
    float rate = max(m_timer / m_totalTime, 0.0f);
    float p = m_power * rate;

    float x = ((rand() % 200) / 100.0f - 1.0f) * p;
    float y = ((rand() % 200) / 100.0f - 1.0f) * p;

    Vector3 pos = m_basePosition;
    pos.x += x;
    pos.y += y;
    g_camera2D->SetPosition(pos);
    g_camera2D->SetTarget({ pos.x, pos.y, 0.0f });
}
揺らしすぎないこと 初心者がやりがちなのは「揺らしすぎ」です。 気持ちよくて強くしたくなりますが、遊ぶ人は酔います。
目安は 5〜15 ピクセル、0.1〜0.2 秒。 「え、揺れた？」くらいでちょうどいいです。

もうひとつの定番「ヒットストップ」

// 当たった瞬間、数フレームだけ時間を止める
if (m_hitStopTimer > 0.0f) {
    m_hitStopTimer -= g_gameTime->GetFrameDeltaTime();
    return;           // ★ 更新をまるごと飛ばす
}

0.05秒ほど止めるだけで、手応えが劇的に変わります。 格闘ゲームやアクションゲームは、ほぼ必ず入れています。

07確認

  1. 「残り時間 ÷ 全体の時間」で何が作れる？
  2. 被弾を伝える手段を3つ挙げる。
  3. 画面を揺らすときの注意は？
答え
  1. 1.0 から 0.0 へ変化する「進み具合」。 フェード・点滅・出現など、あらゆる演出に使える。
  2. 赤く光る／効果音／画面を揺らす／ヒットストップ／エフェクト など。
  3. 揺らしすぎない。5〜15ピクセル、0.1〜0.2秒が目安。
