LV3 表現 ／ 3-09

3Dモデルを表示する

難易度 ／ 前提 2-03

01この章でできるようになること

  • 3Dモデルを画面に出せる
  • 位置・回転・大きさを変えられる
  • 2Dとの座標系の違いが分かる

02いちばん短い例

// Player.h
private:
    ModelRender m_modelRender;
    Vector3     m_position = Vector3::Zero;

// Player.cpp
bool Player::Start()
{
    m_modelRender.Init("Assets/modelData/unityChan.tkm");
    return true;
}

void Player::Update()
{
    m_modelRender.SetPosition(m_position);
    m_modelRender.Update();          // ★ 忘れやすい
}

void Player::Render(RenderContext& rc)
{
    m_modelRender.Draw(rc);
}

SpriteRender とまったく同じ形です。 Init / Update / Draw の3点セット。

032Dと3Dの座標系の違い

2D3D
単位ピクセル（画面が1920×1080） センチメートルくらいの感覚
X右が +右が +
Y上が +上が +
Z使わない奥が +
見え方座標＝画面の位置 カメラ次第
3Dでは「画面に出ない」の原因が増えます
  • カメラが別の方向を向いている
  • カメラの中に埋まっている（近すぎる）
  • 遠すぎて Far の外にいる
  • モデルが極端に小さい／大きい
まず {0, 0, 0} に置いて、 カメラを初期状態にして確認してください。

04回転と大きさ

// 大きさ
m_modelRender.SetScale({ 2.0f, 2.0f, 2.0f });    // 2倍

// 回転（Y軸まわりに90度）
Quaternion rot;
rot.SetRotationDegY(90.0f);
m_modelRender.SetRotation(rot);

回転は Quaternion（クォータニオン）で扱います。 角度3つ（XYZ）で回転を表すと、 組み合わせによっては軸が重なって回らなくなる問題があるためです。

やりたいこと書き方
Y軸まわりに回す（左右を向く） rot.SetRotationDegY(角度)
X軸まわりに回す（上下を向く） rot.SetRotationDegX(角度)
好きな軸まわりに回す rot.SetRotationDeg(軸, 角度)
いまの回転にさらに足す rot.AddRotationDegY(角度)
ベクトルを回す rot.Apply(vec)
クォータニオンの中身は理解しなくて大丈夫です 「回転を入れる箱」だと思ってください。 上の関数だけで、ゲームに必要な回転はほぼ全部できます。 （くわしくは Sample_20 にあります）

05モデルの上方向

m_modelRender.Init("Assets/modelData/xxx.tkm",
    nullptr, 0,
    enModelUpAxisY);      // ★ モデルの上方向

3DCGソフトによって、どの軸が「上」かが違います。 k2Engine の既定は enModelUpAxisZ です。

モデルが横倒しになっていたら、ここです enModelUpAxisY と enModelUpAxisZ を 切り替えて試してください。 90度倒れているときは、ほぼこれが原因です。

06演習

演習1（まねる）

モデルを1体出して、位置を動かす。

演習2（回す）

モデルを毎フレーム少しずつY軸まわりに回転させる。

解答例を見る（まず自分でやってから） 
// Player.h
private:
    float m_angle = 0.0f;

// Player.cpp
void Player::Update()
{
    const float dt = g_gameTime->GetFrameDeltaTime();

    m_angle += 90.0f * dt;        // 1秒で90度
    if (m_angle > 360.0f) {
        m_angle -= 360.0f;        // 大きくなりすぎないように
    }

    Quaternion rot;
    rot.SetRotationDegY(m_angle);
    m_modelRender.SetRotation(rot);

    m_modelRender.SetPosition(m_position);
    m_modelRender.Update();
}
AddRotationDegY を毎フレーム呼ぶのは避ける 
// 一見よさそうだが…
m_rotation.AddRotationDegY(1.5f);    // ★ 誤差が溜まっていく
クォータニオンを掛け続けると、少しずつ誤差が蓄積して、 だんだん形が崩れます。
「角度を float で持っておいて、毎回 SetRotationDegY で作り直す」 ほうが安全です。

演習3（並べる）

モデルを円形に8体並べる。（ヒント：sin と cos、あるいはクォータニオンでベクトルを回す）

解答例を見る（まず自分でやってから）

方法1 ― 三角関数を使う

bool GameScene::Start()
{
    const int   NUM    = 8;
    const float RADIUS = 300.0f;

    for (int i = 0; i < NUM; i++) {
        float rad = Math::PI2 * i / NUM;      // 0 〜 2π を8等分

        Enemy* e = NewGO<Enemy>(enPriority_Enemy, "enemy");
        e->SetPosition({
            cosf(rad) * RADIUS,
            0.0f,
            sinf(rad) * RADIUS
        });
    }
    return true;
}

方法2 ― クォータニオンでベクトルを回す

for (int i = 0; i < NUM; i++) {
    Quaternion rot;
    rot.SetRotationDegY(360.0f / NUM * i);

    Vector3 pos = { RADIUS, 0.0f, 0.0f };     // 基準の位置
    rot.Apply(pos);                            // ★ 回す

    Enemy* e = NewGO<Enemy>(enPriority_Enemy, "enemy");
    e->SetPosition(pos);
}

方法2のほうが読みやすいことが多いです。 「基準の位置を、角度ぶん回す」と素直に書けます。

この考え方は、全方位弾にそのまま使えます 位置ではなく速度ベクトルを回せば、 2-14 の演習でやった全方位弾になります。 
Vector3 dir = { 0.0f, 1.0f, 0.0f };
rot.Apply(dir);
bullet->SetVelocity(dir);

07確認

  1. ModelRender で必要な3つの呼び出しは？
  2. 3Dで Z軸はどちら向き？
  3. モデルが横倒しになるときに疑うのは？
答え
  1. Init（1回）、Update（毎フレーム）、 Draw（毎フレーム）。
  2. 奥が +Z。
  3. enModelUpAxis。Y と Z を切り替える。
