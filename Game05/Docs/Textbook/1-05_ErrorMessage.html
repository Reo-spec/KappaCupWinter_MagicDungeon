LV1 入門 ／ 1-05

エラーメッセージの読み方

難易度 ／ 前提 1-04

01この章でできるようになること

  • エラーが出ても、あわてずに原因の行までたどり着ける
  • よく出る3つのエラーを、自力で直せる
これは「おまけ」の章ではありません プログラミングの時間の多くは、エラーと向き合う時間です。 ここができるかどうかで、この先の進み方がまったく変わります。 いちばん大事な章のひとつだと思ってください。

02まず、あわてない

エラーが50個出ると、心が折れそうになります。でも安心してください。

いちばん上のエラーだけ見ればよい C++のエラーは、1つの間違いから何十個も連鎖します。 セミコロンを1個忘れただけで、40個エラーが出ることもあります。
いちばん上の1個を直して、もう一度ビルドしてください。 残り49個が消えることがよくあります。

エラーの一覧はエラー一覧ウィンドウに出ます。 行をダブルクリックすると、その場所にジャンプします。

03エラー一覧と出力ウィンドウ

ウィンドウ開き方何が見える
エラー一覧 Ctrl+\ → E エラーの一覧。ダブルクリックで飛べる
出力 Ctrl+Alt+O ビルドの全部のログ。実行中のログもここ
エラー一覧が嘘をつくことがあります エラー一覧は、ときどき古い情報を残したままになります。 「直したはずなのにエラーが消えない」と思ったら、 出力ウィンドウのほうを見てください。 こちらが本物です。

04よく出るエラー その1 ― C2065

error C2065: 'm_hp': 定義されていない識別子です。

意味：「m_hp なんて知りません」

原因直し方
打ち間違いm_hp と m_Hp は別物。 C++は大文字と小文字を区別します
宣言していないint m_hp = 100; を .h に書く
#include していないそのクラスのヘッダを読み込む

ほとんどは打ち間違いです。 まずスペルを疑ってください。

05よく出るエラー その2 ― C2143

error C2143: 構文エラー: ';' が '}' の前にありません。

意味：「セミコロンが足りません」

エラーが出た行の、ひとつ上を見る コンパイラは「セミコロンが無い」ことに、 次の行まで来てから気づきます。 だから、本当の間違いは1行上にあることがほとんどです。 
int hp = 100        // ← 本当はここにセミコロンが無い
int mp = 50;        // ← でもエラーはこの行に出る

クラスの定義のあとのセミコロンも、忘れがちです。 

class Player
{
    ...
};      // ← この「;」が必要（忘れやすい）

06よく出るエラー その3 ― LNK2019

error LNK2019: 未解決の外部シンボル "public: void __cdecl Player::Move(void)"
               が関数 ... で参照されました。

意味：「Player::Move を呼んでいるけど、中身がどこにもありません」

これはリンクエラーといって、これまでの2つとは種類が違います。 文法は合っているが、部品が足りないという状態です。

原因直し方
.h に宣言だけ書いて、 .cpp に中身を書いていない .cpp に void Player::Move() { ... } を書く
Player:: を書き忘れた void Move() ではなく void Player::Move()
.cpp をプロジェクトに追加していない ソリューションエクスプローラーで確認する

エラーメッセージの中に、関数の名前がそのまま出ています。 その名前で検索すれば、書き忘れた場所が見つかります。

07エラーメッセージの調べ方

知らないエラーが出たら、エラー番号で検索してください。 

C2660 C++          ← エラー番号 + 言語名
error LNK2001      ← そのまま貼る
検索するときのコツ
  • 変数名やファイル名は消す。 'm_hp' のような、自分だけの名前が入っていると引っかかりません
  • Microsoft の公式ドキュメントが上位に出ます。それが正確です
  • それでも分からなければ、先生や友達に聞いてください。 30分悩むより、5分聞いたほうが速いことがあります

08実行中に落ちたときは

ビルドは通ったのに、実行したら止まった。そういうときは Visual Studio が「例外がスローされました」と教えてくれます。

「中断」を押して、そのまま閉じないでください 止まったその場所に、答えがあります。 どの行で止まったか、変数に何が入っているかを見れば、原因が分かります。
そのやり方は 1-18 デバッガを使う でやります。 いまは「閉じずに、止まった行を見る」とだけ覚えてください。

09演習

演習1（わざと壊す）

Game.cpp のセミコロンを1個消してビルドする。エラーが何個出るか数えて、いちばん上のエラーを読む。

演習2（直す）

次の3つの間違いを1つずつ作って、出るエラー番号をメモする。
① 変数名を打ち間違える　② セミコロンを消す　③ .h に関数を宣言して .cpp に書かない

解答例を見る（まず自分でやってから）
やったこと出るエラー種類
変数名を打ち間違えるC2065コンパイルエラー
セミコロンを消すC2143 などコンパイルエラー
宣言だけして中身を書かないLNK2019リンクエラー

③だけ種類が違うことに気づきましたか。

  • コンパイルエラー（C から始まる） … 文法が間違っている。行番号が出る
  • リンクエラー（LNK から始まる） … 文法は合っているが、部品が足りない。行番号が出ないことが多い

行番号が出ないので、リンクエラーは最初とまどいます。 「LNK が出たら、中身を書き忘れていないか探す」と覚えておいてください。

演習3（読み解く）

次のコードには間違いが3つあります。ビルドする前に探してみてください。
int hp = 100
if (hp = 0) {
OutputDebugStringA("しんだ\\n")
}

解答例を見る（まず自分でやってから） 
int hp = 100        // ① セミコロンが無い
if (hp = 0) {       // ② == ではなく = になっている
    OutputDebugStringA("しんだ\n")   // ③ セミコロンが無い
}

正しくは、こうです。

int hp = 100;
if (hp == 0) {
    OutputDebugStringA("しんだ\n");
}
②がいちばん怖い if (hp = 0) はエラーになりません。 文法としては正しいからです（hp に 0 を代入して、その結果で判定する）。
つまり、コンパイラは何も教えてくれず、 そのうえ hp の値まで 0 に書き換わります。 == と = の取り違えは 1-08 で詳しくやります。

①③のようにエラーが出るものは、まだ幸せです。 ②のようにエラーが出ない間違いのほうが、ずっとやっかいです。

10確認

  1. エラーが50個出た。まず何をする？
  2. C2143（セミコロンが無い）が出たとき、どこを見る？
  3. C で始まるエラーと LNK で始まるエラーの違いは？
答え
  1. いちばん上の1個だけ直して、もう一度ビルドする。連鎖して消えることが多い。
  2. エラーが出た行のひとつ上。
  3. C はコンパイルエラー（文法の間違い、行番号が出る）。 LNK はリンクエラー（中身が足りない、行番号が出ないことが多い）。
