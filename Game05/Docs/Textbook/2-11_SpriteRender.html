スプライトを表示する（SpriteRender）

難易度 ／ 前提 2-03

01この章でできるようになること

  • 画像を画面に出せる
  • 位置・大きさ・回転・色を変えられる
  • 2Dの座標系（どこが原点か）が分かる
画像は自分で用意してください 本文に出てくる player.dds はファイル名の例で、実物はありません。まずは Sample/Sample_06 の画像をコピーして動かすのが早道です。 → 素材の用意のしかた

02いちばん短い例

class Player : public IGameObject {
public:
    bool Start() override;
    void Update() override;
    void Render(RenderContext& rc) override;
private:
    SpriteRender m_spriteRender;
    Vector3      m_position = Vector3::Zero;
};

bool Player::Start()
{
    // 画像のパス、幅、高さ
    m_spriteRender.Init("Assets/sprite/player.dds", 64.0f, 64.0f);
    return true;
}

void Player::Update()
{
    m_spriteRender.SetPosition(m_position);
    m_spriteRender.Update();     // ← 忘れやすい
}

void Player::Render(RenderContext& rc)
{
    m_spriteRender.Draw(rc);
}
3つセットで覚える Init（1回）／ Update（毎フレーム）／ Draw（毎フレーム）。 Update() を呼び忘れると、位置を変えても画面が動きません。 「動かしたはずなのに動かない」の9割はこれです。

032Dの座標系

04できること

関数説明
SetPosition(Vector3)位置。中心が基準
SetScale(Vector3)拡大率。{2,2,1} で2倍
SetRotation(Quaternion)回転
SetMulColor(Vector4)色をかけ算。{1,0,0,1} で赤くなる
SetPivot(Vector2)基準点。{0.5, 0.5} が中心、{0, 0} が左下

回転は Quaternion を使います。2Dなら Z軸まわりだけ考えれば充分です。

Quaternion rot;
rot.SetRotationDegZ(45.0f);      // Z軸まわりに45度
m_spriteRender.SetRotation(rot);

半透明にしたり、点滅させたりするのは色（MulColor）で行います。

// 半透明にする（4つめがα）
m_spriteRender.SetMulColor({ 1.0f, 1.0f, 1.0f, 0.5f });

// 被弾したら赤くする
m_spriteRender.SetMulColor({ 1.0f, 0.3f, 0.3f, 1.0f });

05画像の用意

k2Engine が読めるのは .dds 形式です。 PNGやJPGはそのままでは読めません。

  1. 画像を用意する（透過させたい部分はαチャンネルを透明に）
  2. ツールで .dds に変換する
  3. Game/Assets/sprite/ に置く
  4. Init("Assets/sprite/なまえ.dds", 幅, 高さ) で読み込む
パスは実行ファイルからではなく、プロジェクトからの相対 "Assets/sprite/player.dds" と書きます。 "../Assets/..." や絶対パスにしてはいけません。 提出したときに他のPCで読めなくなります。

06よくあるエラー

画面に何も出ない

原因1：Render() で Draw() を呼んでいない。
原因2：Update() で m_spriteRender.Update() を呼んでいない。
原因3：画面の外にいる。位置を {0, 0, 0} にして確かめる。
原因4：ファイルのパスが違う。出力ウィンドウにエラーが出ていないか見る。

動かしたのに動かない

原因：SetPosition のあとに Update() を呼んでいない。
直し方：SetPosition → Update() の順で必ず呼ぶ。

ほかのものに隠れる

原因：優先度が小さい。
直し方：2-04 のとおり、 手前に出したいものは優先度を大きくする。

07演習

演習1（まねる）

画像を1枚、画面の中央に出す。

演習2（動かす）

スティックで動かし、画面の端から出ないようにする。 （座標の範囲は -960〜960、-540〜540 です）

解答例を見る（まず自分でやってから） 
void Player::Update()
{
    const float dt = g_gameTime->GetFrameDeltaTime();

    m_position.x += g_pad[0]->GetLStickXF() * 500.0f * dt;
    m_position.y += g_pad[0]->GetLStickYF() * 500.0f * dt;

    // 画面の外に出さない。
    // 画面の半分（960, 540）から、絵の半分（32）だけ内側で止める。
    const float LIMIT_X = 960.0f - 32.0f;
    const float LIMIT_Y = 540.0f - 32.0f;

    if (m_position.x < -LIMIT_X) { m_position.x = -LIMIT_X; }
    if (m_position.x >  LIMIT_X) { m_position.x =  LIMIT_X; }
    if (m_position.y < -LIMIT_Y) { m_position.y = -LIMIT_Y; }
    if (m_position.y >  LIMIT_Y) { m_position.y =  LIMIT_Y; }

    m_spriteRender.SetPosition(m_position);
    m_spriteRender.Update();
}

min / max を使うと短く書けます。どちらでも構いません。 

m_position.x = max(-LIMIT_X, min(LIMIT_X, m_position.x));

演習3（自分で書く）

1秒かけて半透明になって消えるスプライトを作る。 消えたら DeleteGO(this) する。 本文には答えがありません。

解答例を見る（まず自分でやってから） 
// FadeOutSprite.h
private:
    SpriteRender m_spriteRender;
    Vector3      m_position = Vector3::Zero;
    float        m_alpha = 1.0f;
    static const float FADE_TIME;    // 消えるまでの秒数

// FadeOutSprite.cpp
const float FadeOutSprite::FADE_TIME = 1.0f;

void FadeOutSprite::Update()
{
    const float dt = g_gameTime->GetFrameDeltaTime();

    // 1秒で 1.0 → 0.0 にする
    m_alpha -= dt / FADE_TIME;

    if (m_alpha <= 0.0f) {
        DeleteGO(this);
        return;                      // ★ 忘れない
    }

    m_spriteRender.SetMulColor({ 1.0f, 1.0f, 1.0f, m_alpha });
    m_spriteRender.SetPosition(m_position);
    m_spriteRender.Update();
}

ポイント

  • dt / FADE_TIME で「1秒かけて1.0減らす」になります。 FADE_TIME を2.0にすれば2秒かけて消えます
  • 4つめの値（α）が透明度です。1.0で不透明、0.0で完全に透明
  • Init のとき AlphaBlendMode_Trans（既定値）になっていること

これができると、爆発の煙やダメージ表示など、いろいろな演出に応用できます。

08確認

  1. スプライトを使うのに必要な3つの呼び出しは？
  2. 画面の中央の座標は？ 上はプラスかマイナスか？
  3. SetPosition で指定するのは画像のどこ？
答え
  1. Init（1回）、Update（毎フレーム）、Draw（毎フレーム）。
  2. (0, 0)。上がプラス。
  3. 中心（既定のピボットが {0.5, 0.5} のため）。
