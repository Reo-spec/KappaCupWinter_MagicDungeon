配列と std::vector

難易度 ／ 前提 1-10

01この章でできるようになること

  • たくさんの値をまとめて持てる
  • 配列の外を触ると何が起きるかを知っている
  • std::vector で、数が変わるものを扱える

02配列は「箱が並んだもの」

int scores[5] = { 10, 20, 30, 40, 50 };

scores[0] = 100;      // 1番目（0から数える）
int a = scores[4];    // 5番目 = 50

03範囲外を触るとどうなるか

エラーにならずに、よその場所を書き換えます 
int scores[5];
scores[5] = 999;      // ← 範囲外。でもビルドは通る
C++は、配列の範囲をチェックしてくれません。 その場所にあった別の変数が、勝手に 999 に書き換わります。
結果、まったく関係ない場所でおかしな動きをします。 原因を突き止めるのが非常に大変なバグです。

Debug ビルドなら、運がよければその場で止めてくれます。 これも Debug で開発する理由のひとつです。

04std::vector ― 数が変わる配列

配列は、最初に個数を決めなければいけません。 弾のように「増えたり減ったりするもの」には向きません。 そこで std::vector を使います。 

#include <vector>     // ← k2Engine ではすでに読み込まれているので不要

std::vector<int> scores;      // 空っぽで始まる

scores.push_back(10);         // 後ろに足す
scores.push_back(20);
scores.push_back(30);

int n = (int)scores.size();   // いくつ入っているか → 3
int a = scores[0];            // 取り出す → 10

scores.clear();               // 全部消す
関数意味
push_back(値)後ろに1つ足す
size()いま何個入っているか
empty()空っぽか（size() == 0 と同じ）
clear()全部消す
[i]i番目を取り出す。範囲チェックは無い

05全部まわす

// 書き方1：添字を使う
for (int i = 0; i < (int)scores.size(); i++) {
    total += scores[i];
}

// 書き方2：範囲for（こちらが読みやすい）
for (int score : scores) {
    total += score;
}

添字が要らないなら、範囲forを使ってください。 短いうえに、範囲外アクセスの事故が起きません。

size() は int ではありません size() が返すのは size_t という別の型です。 int と比べると警告 C4018 が出ます。
(int)scores.size() のように書けば消えます。 （なぜ別の型なのかは、いまは気にしなくて大丈夫です）

06演習

演習1（まねる）

std::vector<int> に5つの数を入れて、合計を計算して表示する。

演習2（増やす）

Aボタンを押すたびに vector に数を足して、いま何個入っているかを表示する。

解答例を見る（まず自分でやってから） 
// Game.h
private:
    std::vector<int> m_values;

// Game.cpp
void Game::Update()
{
    if (g_pad[0]->IsTrigger(enButtonA)) {
        m_values.push_back(rand() % 100);
    }
    if (g_pad[0]->IsTrigger(enButtonB)) {
        m_values.clear();
    }

    int total = 0;
    for (int v : m_values) {
        total += v;
    }

    wchar_t text[256];
    swprintf_s(text, 256, L"個数 %d / 合計 %d",
        (int)m_values.size(), total);
    m_fontRender.SetText(text);
}

これが「弾が増えたり減ったりする」の原型です。 LV2では、int ではなくゲームオブジェクトを管理することになります。

演習3（壊してみる）

わざと範囲外にアクセスしてみる。int a[5]; を作って a[10] = 999; と書いたら何が起きるか。（Gitでコミットしてから試してください）

解答例を見る（まず自分でやってから） 
void Game::Update()
{
    int a[5] = { 1, 2, 3, 4, 5 };
    int b = 111;              // すぐ隣に置かれることが多い

    a[5] = 999;               // ★ 範囲外

    wchar_t text[256];
    swprintf_s(text, 256, L"b = %d", b);    // 111 のはずが…
    m_fontRender.SetText(text);
}

起こりうること（どれになるかは運です）

  • b の値が 999 に書き換わる
  • Debug ビルドなら 「Stack around the variable 'a' was corrupted」 というエラーで止まる
  • 何も起きない（いちばん怖い）
この「何も起きないことがある」が最悪です 自分のPCでは平気なのに、提出した先で落ちる。 C++でいちばん怖いバグの形です。
同じ種類の事故を 2-08 でもう一度扱います。 そのときは「あぁ、これか」と思えるはずです。

だから、範囲forを使ってください。 そもそも添字を書かなければ、この事故は起きません。

07確認

  1. int a[5] の、使える添字の範囲は？
  2. 範囲外にアクセスするとどうなる？ エラーは出る？
  3. 配列と std::vector の使い分けは？
答え
  1. 0 から 4 まで。
  2. よその場所を読み書きする。エラーにならないことが多い。 Debugなら止まってくれることもある。
  3. 個数が決まっていて変わらないなら配列。 増減するなら std::vector。
