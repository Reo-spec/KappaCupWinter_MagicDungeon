LV1 入門 ／ 1-06

変数と型

難易度 ／ 前提 1-04

01この章でできるようになること

  • 変数を作って、値を入れられる
  • int / float / bool を使い分けられる
  • 値を画面に出して確かめられる

02変数は「名前のついた箱」

プログラムは、数字を覚えておく場所が必要です。 HP、スコア、座標。それを入れる箱が変数です。 

int hp = 100;
部分意味
int型。この箱に何を入れられるか
hp名前。自分で決める
= 100初期値。最初に入れておく値
;文の終わり。忘れると C2143

033つの型を覚える

C++にはたくさんの型がありますが、まずはこの3つだけで充分です。

型入るもの例ゲームでの用途
int整数。小数は入らない 100, -3, 0 HP、スコア、残機、個数
float小数 1.5f, -0.25f 座標、速さ、時間、角度
booltrue か false だけ true, false 生きているか、無敵か、ボタンが押されたか
 
int   score   = 0;
float speed   = 3.5f;
bool  isAlive = true;
float には f を付ける 3.5 と書くと、C++では double（もっと精度の高い小数）になります。 float に入れるときは 3.5f と書いてください。
付けなくても動きますが、警告が出ますし、ほんの少し遅くなります。 ゲームでは float を使うのが基本です。

04名前の付け方

だめな名前よい名前理由
a, b, x1hp, score 何のための値か分からない
hp2maxHp 番号ではなく、意味で区別する
flagisAlive bool は is〜 で始めると、true/false の意味が分かる

また、k2Engine ではクラスのメンバ変数に m_ を付ける 決まりになっています。 

int m_hp = 100;         // クラスの中の変数（メンバ変数）
int localValue = 0;     // 関数の中だけの変数（ローカル変数）

m_ が付いていれば「これはクラスのもの」と一目で分かります。 エンジンのコードも全部そうなっているので、まねしてください。

05画面に出して確かめる

変数の値を見られないと、勉強になりません。 「表示係」を用意します。 Game.h と Game.cpp を、こう書き換えてください。 

// Game.h
#pragma once

class Game : public IGameObject
{
public:
    Game() {}
    ~Game() {}
    bool Start();
    void Update();
    void Render(RenderContext& rc);

private:
    FontRender m_fontRender;     // ← 表示係（おまじない）

    int   m_hp    = 100;         // ★ ここに変数を書いていく
    float m_speed = 3.5f;
    bool  m_isAlive = true;
};
// Game.cpp
bool Game::Start()
{
    // 表示係の設定（おまじない）
    m_fontRender.SetPosition(Vector3(-900.0f, 400.0f, 0.0f));
    m_fontRender.SetScale(1.5f);
    return true;
}

void Game::Update()
{
    // ★ ここで変数を見る
    wchar_t text[256];
    swprintf_s(text, 256, L"hp=%d  speed=%.2f  alive=%d",
        m_hp, m_speed, m_isAlive);
    m_fontRender.SetText(text);
}

void Game::Render(RenderContext& rc)
{
    m_fontRender.Draw(rc);
}
「表示係」は、いまは意味が分からなくてよい FontRender のあたりは、画面に文字を出すためのおまじないです。 中身は 2-12 でやります。 いまは「この形で書けば数字が出る」とだけ覚えて、 変数のほうに集中してください。

%d と %.2f のところに、変数の値が入ります。

書き方意味
%dint を10進数で表示
%ffloat を表示
%.2ffloat を小数点以下2桁で表示

06もうひとつの表示方法

画面ではなく、Visual Studio の出力ウィンドウに出す方法もあります。 こちらは過去のぶんも全部残るので、 「何回呼ばれたか」を調べるのに向いています。 

char text[256];
sprintf_s(text, "hp = %d\n", m_hp);
OutputDebugStringA(text);

出力ウィンドウは Ctrl+Alt+O で開きます。

毎フレーム出すと、出力が洪水になります Update() の中で OutputDebugStringA を呼ぶと、 1秒に60行出ます。 必要なときだけ出すか、確認が終わったら消してください。 （大量に出すと、ゲーム自体もかなり遅くなります）

07よくあるエラー

値がおかしい／変な数字が出る

原因：%d と %f を間違えている。
int を %f で表示しようとすると、 まったく関係ない数字が出ます。

初期値を書かないとどうなる？

int hp;        // 初期値なし

何が入っているか分かりません。 前にそのメモリを使っていた誰かのゴミが残っています。 -858993460 のような、意味不明な数字が出ることがあります。

変数は必ず初期値を書く これは一生守ってほしい習慣です。 初期化していない変数が原因のバグは、毎回動きが変わるので、 原因を突き止めるのが非常に大変です。

08演習

演習1（まねる）

上の「表示係」を用意して、3つの変数を画面に出す。

演習2（変えてみる）

変数を増やして、自分のキャラクターのステータスを表示する。（名前以外の、HP・攻撃力・素早さ・生きているか、など）

解答例を見る（まず自分でやってから） 
// Game.h
private:
    FontRender m_fontRender;

    int   m_hp     = 100;
    int   m_attack = 25;
    float m_speed  = 4.5f;
    bool  m_isAlive = true;

// Game.cpp
void Game::Update()
{
    wchar_t text[256];
    swprintf_s(text, 256,
        L"HP %d / ATK %d / SPD %.1f / ALIVE %d",
        m_hp, m_attack, m_speed, m_isAlive);
    m_fontRender.SetText(text);
}

bool は %d で表示すると true なら 1、false なら 0 が出ます。

文字で出したいなら、こう書けます（?: は 1-08 で扱います）。 

swprintf_s(text, 256, L"ALIVE %s", m_isAlive ? L"true" : L"false");

演習3（実験する）

int の変数に 3.7f を入れるとどうなるでしょうか。予想してから試してください。

解答例を見る（まず自分でやってから） 
int a = 3.7f;      // 3 になる（小数点以下が切り捨てられる）

四捨五入ではなく、切り捨てです。 3.9f を入れても 3 になります。

このとき、コンパイラは警告を出します。 

warning C4244: '初期化中': 'float' から 'int' への変換です。データが失われる可能性があります。
警告を無視しないでください エラーではないのでビルドは通りますが、警告は「ここ、おかしくないですか？」 というコンパイラからの指摘です。
ゲーム会社では「警告ゼロ」を求められることも多いです。 いまのうちに「警告が出たら直す」を習慣にしておくと、あとで楽になります。

わざと切り捨てたいときは、そう書いたと分かるようにします。 

int a = (int)3.7f;      // わざと切り捨てている、と読める

09確認

  1. int / float / bool に入るものは？
  2. 3.5 ではなく 3.5f と書くのはなぜ？
  3. 変数に初期値を書かないとどうなる？
答え
  1. 整数 / 小数 / true か false。
  2. f が無いと double になる。 ゲームでは float を使うのが基本。
  3. 何が入っているか分からない（前に使われた値のゴミが残る）。 毎回動きが変わるバグになる。
