LV1 入門 ／ 1-09

for文・while文 ― 繰り返す

難易度 ／ 前提 1-08

01この章でできるようになること

  • 同じ処理を何回も繰り返せる
  • 無限ループを作ってしまったとき、自分で止められる

02for文

for (int i = 0; i < 10; i++) {
    // ここが10回実行される。i は 0, 1, 2, ... 9 と変わる
}
部分意味いつ動く
int i = 0最初の準備最初に1回だけ
i < 10続ける条件毎回、回る前に確認
i++1回終わるたびの処理毎回、回り終わったあと
0から始まって、10は含まない i < 10 なので、i は 0〜9 の10回です。 1〜10 ではありません。
プログラミングでは0から数えるのが基本です。 最初は気持ち悪いですが、慣れます。

03while文

while (hp > 0) {
    // hp が 0 より大きいあいだ、ずっと繰り返す
}

回数が決まっているなら for、 決まっていないなら while と覚えてください。

条件が変わらないと、永遠に止まりません 
while (hp > 0) {
    OutputDebugStringA("まだ生きてる\n");
    // hp を減らしていない！ → 永遠に終わらない
}
これを無限ループと呼びます。 ゲームが固まって、応答しなくなります。

止め方：Visual Studio の 「すべて中断」（Ctrl+Alt+Break） を押してください。止まった場所が表示されます。 それでもだめなら Shift+F5 でデバッグを終了します。

04途中でやめる・飛ばす

for (int i = 0; i < 100; i++) {
    if (i == 10) {
        break;       // ループをやめる
    }
    if (i % 2 == 0) {
        continue;    // このまわりだけ飛ばして、次へ
    }
    // ここは奇数のときだけ通る（1, 3, 5, 7, 9）
}

continue は「早めに次へ行く」ときによく使います。 if の入れ子が深くなるのを防げます。 

// 入れ子が深い
for (auto enemy : enemies) {
    if (enemy != nullptr) {
        if (enemy->IsAlive()) {
            enemy->Update();
        }
    }
}

// continue で浅くする（こちらが読みやすい）
for (auto enemy : enemies) {
    if (enemy == nullptr)      { continue; }
    if (enemy->IsAlive() == false) { continue; }
    enemy->Update();
}

05文字を並べてみる

void Game::Update()
{
    wchar_t text[256] = L"";      // 空っぽの文字列

    for (int i = 0; i < m_hp / 10; i++) {
        wcscat_s(text, 256, L"■");    // 後ろにくっつける
    }

    m_fontRender.SetText(text);
}

HPが100なら ■ が10個、50なら5個並びます。 簡易的なHPバーになります。

06よくあるエラー

ゲームが固まる

原因：無限ループ。
直し方：Ctrl+Alt+Break で中断して、 止まった場所を見る。条件が変わるコードを書き忘れていないか確認する。

for のあとにセミコロン

for (int i = 0; i < 10; i++);    // ← このセミコロン
{
    // 1回しか実行されない
}

if と同じ事故です。エラーになりません。

1回多い／1回少ない

i < 10（10回）と i <= 10（11回）を間違える。 これは「オフバイワンエラー」と呼ばれる、非常に有名な間違いです。 ベテランでも間違えます。

07演習

演習1（まねる）

上のHPバーを作る。ボタンでHPを減らして、■ が減るのを見る。

演習2（数える）

1から100までを全部足すといくつになるか、for で計算して表示する。

解答例を見る（まず自分でやってから） 
void Game::Update()
{
    int sum = 0;
    for (int i = 1; i <= 100; i++) {
        sum += i;
    }

    wchar_t text[256];
    swprintf_s(text, 256, L"1から100の合計 = %d", sum);
    m_fontRender.SetText(text);
}

答えは 5050 です。

ここでは i <= 100 と書いています。 「1から100まで」なので、100を含めたいからです。 i < 100 にすると99までになり、答えが 4950 になります。

この計算を毎フレームやる意味はありません 答えはいつも同じなのに、1秒に60回も計算しています。 本来は Start() で1回計算して、覚えておけば充分です。
「毎フレームやる必要があるか？」を考える癖をつけてください。 これは LV5 最適化 につながる考え方です。

演習3（壊して直す）

わざと無限ループを作って、ゲームを固める。そして Ctrl+Alt+Break で止めて、どこで止まっているかを確認する。

解答例を見る（まず自分でやってから） 
void Game::Update()
{
    int i = 0;
    while (i < 10) {
        // i++ を書かない → 永遠に終わらない
        OutputDebugStringA("loop\n");
    }
}

Ctrl+Alt+Break を押すと、 while の中の行で止まります。 「ここをぐるぐる回っている」と分かります。

このときローカルウィンドウを見ると、 i がずっと 0 のままなのが見えます。 これが原因です。

この操作が、そのままデバッグの基本です 「固まった → 中断 → どこで止まっているか見る → 変数を見る」
1-18 デバッガを使う で、 この流れを本格的にやります。 いま体験しておくと、あの章がとても楽になります。

08確認

  1. for (int i = 0; i < 5; i++) は何回まわる？ i の値は？
  2. 無限ループになったら、どうやって止める？
  3. break と continue の違いは？
答え
  1. 5回。i は 0, 1, 2, 3, 4。
  2. Ctrl+Alt+Break で中断する。
  3. break はループを抜ける。 continue はそのまわりだけ飛ばして次へ進む。
