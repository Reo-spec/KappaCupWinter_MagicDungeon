カメラ

難易度 ／ 前提 3-09

01この章でできるようになること

  • カメラを動かせる
  • プレイヤーを追いかけるカメラが作れる
  • 「画面に出ない」ときにカメラを疑えるようになる

02カメラは2つある

変数用途
g_camera3D3Dを映すカメラ。ふつうこちら
g_camera2D2D用。さわる必要はほぼない

どちらもグローバル変数です。どこからでも使えます。

03カメラに必要なのは2点だけ

g_camera3D->SetPosition({ 0.0f, 200.0f, -500.0f });   // どこから
g_camera3D->SetTarget  ({ 0.0f,   0.0f,    0.0f });   // どこを見る

「目の位置」と「見ている点」。この2つで向きが決まります。

Position と Target が同じだと壊れます 向きが計算できないため、画面が真っ黒になったり、 おかしな絵になったりします。 プレイヤーの位置をそのまま両方に入れてしまう、というミスが起きがちです。

04その他の設定

関数意味既定値の目安
SetUpどちらが「上」か {0,1,0}
SetNearこれより近いものは映らない 1.0f
SetFarこれより遠いものは映らない 10000.0f
SetViewAngle画角（ラジアン） Math::DegToRad(60.0f)
Near と Far の比が大きすぎると、Zファイティングが起きます 遠くの面がちらちらとちらつく症状です。 深度の精度が足りなくなるために起きます。
Near を大きくする（0.1 ではなく 1.0 にする）のがいちばん効きます。 Far を減らすより効果的です。

05追いかけるカメラ

いちばんよく作るカメラです。 プレイヤーの少し後ろ、少し上から見るだけ。 

// GameCamera.h
class GameCamera : public IGameObject {
public:
    void Update() override;
private:
    GOHandle<Player> m_player;
    Vector3 m_toCameraPos = { 0.0f, 200.0f, -500.0f };  // プレイヤーからの相対位置
};

// GameCamera.cpp
void GameCamera::Update()
{
    Player* player = m_player.Get();
    if (player == nullptr) {
        player = FindGO<Player>("player");
        if (player == nullptr) {
            return;                       // まだいない
        }
        m_player = GOHandle<Player>(player);
    }

    Vector3 target = player->GetPosition();
    Vector3 pos    = target + m_toCameraPos;

    g_camera3D->SetTarget(target);
    g_camera3D->SetPosition(pos);
    g_camera3D->Update();                 // ★ 忘れやすい
}

優先度は、プレイヤーより後にしてください。 プレイヤーが動いたあとの位置を使わないと、 1フレームぶん遅れてカメラが揺れます。 

enPriority_Player = 2,
enPriority_Camera = 8,          // ★ プレイヤーより後
enPriority_UI     = 10,

06なめらかに追いかける

上のコードはプレイヤーにぴったり張り付くので、 動きが硬く見えます。少し遅れて追いつくようにすると自然になります。 

// いまのカメラ位置から、目標位置へ 10% ずつ近づく
m_currentTarget += (target - m_currentTarget) * 0.1f;
m_currentPos    += (pos    - m_currentPos)    * 0.1f;

g_camera3D->SetTarget(m_currentTarget);
g_camera3D->SetPosition(m_currentPos);

0.1 を小さくするほど、ゆるく追いかけます。 0.05〜0.2 のあいだで好みを探してください。

この式は、いろいろな場所で使えます 現在値 += (目標値 - 現在値) * 係数
HPバーがじわっと減る、音量がフェードする、 敵がゆっくりこちらを向く。全部これで書けます。

07演習

演習1（まねる）

カメラの位置をキー操作で前後に動かして、見え方の変化を確認する。

演習2（追う）

プレイヤーを追いかけるカメラを作る。なめらかに追いかける版にする。

解答例を見る（まず自分でやってから） 
// GameCamera.h
#pragma once

class Player;

class GameCamera : public IGameObject {
public:
    bool Start()  override;
    void Update() override;

private:
    GOHandle<Player> m_player;
    Vector3 m_toCameraPos  = { 0.0f, 200.0f, -500.0f };
    Vector3 m_currentPos    = Vector3::Zero;
    Vector3 m_currentTarget = Vector3::Zero;
    bool    m_isFirst = true;
};

// GameCamera.cpp
bool GameCamera::Start()
{
    g_camera3D->SetNear(1.0f);
    g_camera3D->SetFar(10000.0f);
    return true;
}

void GameCamera::Update()
{
    Player* player = m_player.Get();
    if (player == nullptr) {
        player = FindGO<Player>("player");
        if (player == nullptr) {
            return;
        }
        m_player = GOHandle<Player>(player);
    }

    Vector3 target = player->GetPosition();
    Vector3 pos    = target + m_toCameraPos;

    if (m_isFirst) {
        // 初回はいきなり合わせる（でないと原点から飛んでくる）
        m_currentTarget = target;
        m_currentPos    = pos;
        m_isFirst = false;
    }
    else {
        m_currentTarget += (target - m_currentTarget) * 0.1f;
        m_currentPos    += (pos    - m_currentPos)    * 0.1f;
    }

    g_camera3D->SetTarget(m_currentTarget);
    g_camera3D->SetPosition(m_currentPos);
    g_camera3D->Update();
}
初回の処理を忘れると、ゲーム開始時にカメラが飛んできます m_currentPos は最初 (0,0,0) なので、 そこからプレイヤーの位置まで、じわーっと移動する絵になります。 m_isFirst で1回だけ直接代入してください。

優先度の確認も忘れずに。 プレイヤー（2）より後（8）にしないと、カメラが1フレーム遅れます。

演習3（揺らす）

画面を揺らす（カメラシェイク）機能を足す。被弾や爆発のときに呼ぶ。本文には答えがありません。

解答例を見る（まず自分でやってから） 
// GameCamera.h
public:
    void Shake(float power, float time);

private:
    float m_shakePower = 0.0f;
    float m_shakeTimer = 0.0f;
    float m_shakeTotal = 0.0f;

// GameCamera.cpp
void GameCamera::Shake(float power, float time)
{
    // 弱い揺れで上書きしない
    if (power < m_shakePower * (m_shakeTimer / max(m_shakeTotal, 0.0001f))) {
        return;
    }
    m_shakePower = power;
    m_shakeTimer = time;
    m_shakeTotal = time;
}

void GameCamera::Update()
{
    ... 追従の計算 ...

    Vector3 finalPos    = m_currentPos;
    Vector3 finalTarget = m_currentTarget;

    if (m_shakeTimer > 0.0f) {
        m_shakeTimer -= g_gameTime->GetFrameDeltaTime();
        float rate = max(m_shakeTimer / m_shakeTotal, 0.0f);
        float p = m_shakePower * rate;             // だんだん収まる

        Vector3 offset = {
            (rand() / (float)RAND_MAX - 0.5f) * 2.0f * p,
            (rand() / (float)RAND_MAX - 0.5f) * 2.0f * p,
            0.0f
        };
        finalPos    += offset;
        finalTarget += offset;                     // ★ 両方ずらす
    }

    g_camera3D->SetTarget(finalTarget);
    g_camera3D->SetPosition(finalPos);
    g_camera3D->Update();
}

大事なところ

やること理由
Position と Target を同じだけずらす 片方だけだと視線がぐるぐる回って気持ち悪くなる
時間とともに弱めるいきなり止まると不自然
m_currentPos 自体はずらさない 揺れが追従の計算に混ざると、発散する

使うとき

// 被弾
FindGO<GameCamera>("gameCamera")->Shake(15.0f, 0.2f);

// 爆発
FindGO<GameCamera>("gameCamera")->Shake(40.0f, 0.4f);
揺れは「思っているより短く、弱く」 0.15〜0.3秒くらいで充分です。 長いと画面酔いします。 強さも、最初は小さめから試してください。

設定で切れるようにしておくと親切です。 カメラの揺れが苦手な人は少なくありません。

08確認

  1. カメラの向きを決めるのに必要な2つは？
  2. カメラの優先度を、プレイヤーより後にするのはなぜ？
  3. 遠くの面がちらつくときは、どこを直す？
答え
  1. SetPosition（目の位置）と SetTarget（見る点）。
  2. プレイヤーが動いたあとの位置を使うため。 先に動くと1フレーム遅れて揺れる。
  3. SetNear を大きくする。
