02ボスは「状態が変わる敵」

ふつうの敵は「出てきて、まっすぐ進んで、やられる」だけです。 ボスはそうではありません。

  • 登場する（無敵。画面の上から降りてくる）
  • 攻撃パターンA（左右に動きながら弾をばらまく）
  • 攻撃パターンB（HPが半分以下になったら、突進してくる）
  • やられる（大きく爆発してから消える）

これを if で書こうとすると、すぐに読めなくなります。 

// こうなってはいけない
if (m_isEntering) {
    ...
} else if (!m_isEntering && m_hp > m_maxHp / 2 && m_timer < 3.0f) {
    ...
} else if (...) {
    // どの条件がどの行動なのか、もう分からない
}

03ステートマシンで書く

「いま何をしているか」をひとつの変数で持ちます。 状態ごとに関数を分ければ、それぞれが短くなります。 

// Boss.h
class Boss : public IGameObject {
public:
    bool Start() override;
    void Update() override;
    void Render(RenderContext& rc) override;
    void TakeDamage(int damage);

private:
    enum EnState {
        enState_Enter,      // 登場中（無敵）
        enState_AttackA,    // 攻撃パターンA
        enState_AttackB,    // 攻撃パターンB（HP半分以下）
        enState_Dying,      // やられた
    };

    void ChangeState(EnState next);

    void UpdateEnter();
    void UpdateAttackA();
    void UpdateAttackB();
    void UpdateDying();

private:
    EnState m_state = enState_Enter;
    float   m_stateTimer = 0.0f;     // 状態に入ってからの秒数
    int     m_hp = 200;
    int     m_maxHp = 200;
    Vector3 m_position = Vector3::Zero;
};
// Boss.cpp
void Boss::ChangeState(EnState next)
{
    m_state = next;
    m_stateTimer = 0.0f;      // 状態が変わったら必ず0に戻す
}

void Boss::Update()
{
    m_stateTimer += g_gameTime->GetFrameDeltaTime();

    switch (m_state) {
    case enState_Enter:   UpdateEnter();   break;
    case enState_AttackA: UpdateAttackA(); break;
    case enState_AttackB: UpdateAttackB(); break;
    case enState_Dying:   UpdateDying();   break;
    }

    m_spriteRender.SetPosition(m_position);
    m_spriteRender.Update();
}
m_stateTimer が効きます 「状態に入ってから何秒たったか」を持っておくと、 「3秒たったら次の状態へ」「1秒ごとに弾を撃つ」が簡単に書けます。 ChangeState() で必ず0に戻すのを忘れないでください。

04状態ごとの中身

void Boss::UpdateEnter()
{
    // 上から降りてくる。
    m_position.y -= 150.0f * g_gameTime->GetFrameDeltaTime();

    if (m_position.y <= 320.0f) {
        m_position.y = 320.0f;
        ChangeState(enState_AttackA);
    }
}

void Boss::UpdateAttackA()
{
    // 左右に揺れる。
    m_position.x = sinf(m_stateTimer * 1.5f) * 500.0f;

    // 0.5秒ごとに弾をばらまく。
    if (m_stateTimer >= m_nextShotTime) {
        ShootWay(5);
        m_nextShotTime += 0.5f;
    }
}

void Boss::TakeDamage(int damage)
{
    if (m_state == enState_Enter || m_state == enState_Dying) {
        return;              // 登場中とやられ中は無敵
    }
    m_hp -= damage;

    if (m_hp <= 0) {
        ChangeState(enState_Dying);
        return;
    }
    // HPが半分を切ったら、攻撃パターンを変える。
    if (m_state == enState_AttackA && m_hp <= m_maxHp / 2) {
        ChangeState(enState_AttackB);
    }
}

ひとつひとつの関数が短いことに注目してください。 状態が増えても、関数が1つ増えるだけです。 if の入れ子が深くなることはありません。

05この書き方の限界

状態が10個、20個と増えると、このやり方でもつらくなってきます。

  • switch に追加するのを忘れる
  • Boss.cpp が1000行を超える
  • 別の敵でも同じ仕組みを使いたいのに、コピペするしかない
そのつらさは、正しい感覚です LV4-05 State パターンで、 状態そのものをクラスにするやり方を学びます。 でも、いまはこの書き方で完成させてください。 つらさを感じていないのにパターンを使うと、無駄に複雑になるだけです。

06動かして確かめる

  • ボスが上から降りてきて、所定の位置で止まる
  • 降りてくる間は、撃ってもダメージが入らない
  • HPが半分になると、動きが変わる
  • 倒すと、爆発してから消える

いまの状態をデバッグパネルに出すと、確認がとても楽になります。 次の章でやります。

07演習

演習1（まねる）

4つの状態を持つボスを作る。

演習2（増やす）

攻撃パターンをもう1つ増やして、AとBを交互に繰り返すようにする。

解答例を見る（まず自分でやってから） 
// Boss.h
private:
    enum EnState {
        enState_Enter,
        enState_AttackA,
        enState_AttackB,
        enState_Dying,
    };
    static const float ATTACK_TIME;     // 1つの攻撃を続ける秒数

// Boss.cpp
const float Boss::ATTACK_TIME = 6.0f;

void Boss::UpdateAttackA()
{
    m_position.x = sinf(m_stateTimer * 1.5f) * 500.0f;

    if (m_stateTimer >= m_nextShotTime) {
        ShootWay(5);
        m_nextShotTime += 0.5f;
    }

    // 一定時間たったら B へ。
    if (m_stateTimer >= ATTACK_TIME) {
        ChangeState(enState_AttackB);
    }
}

void Boss::UpdateAttackB()
{
    // 自機に向かって突進する。
    Player* player = m_player.Get();
    if (player != nullptr) {
        Vector3 toPlayer = player->GetPosition() - m_position;
        toPlayer.Normalize();
        m_position += toPlayer * 250.0f * g_gameTime->GetFrameDeltaTime();
    }

    // 一定時間たったら A へ戻る。
    if (m_stateTimer >= ATTACK_TIME) {
        ChangeState(enState_AttackA);
    }
}

ChangeState() が m_stateTimer を0に戻してくれるので、 それぞれの状態で「入ってから何秒か」を同じように書けます。 これがステートマシンの気持ちよさです。

HPで切り替えるか、時間で切り替えるか 本文ではHPで、この演習では時間で切り替えました。両方あってよいです。 「HPが半分を切ったら第2形態、その中でAとBを交互に」のように組み合わせると、 ボスらしくなります。

演習3（自分で書く）

状態が変わった瞬間だけ1回やりたい処理（例：登場時に効果音）は、 どこに書けばよいでしょうか。 ChangeState() を工夫して、きれいに書けるようにする。 本文には答えがありません。

解答例を見る（まず自分でやってから）

ChangeState() の中で、入場処理を呼んでしまうのがいちばん簡単です。 

void Boss::ChangeState(EnState next)
{
    m_state = next;
    m_stateTimer = 0.0f;
    m_nextShotTime = 0.0f;

    OnEnterState(next);      // ★ 状態に入った瞬間の処理
}

void Boss::OnEnterState(EnState state)
{
    switch (state) {
    case enState_Enter:
        PlaySe(enSound_BossAppear);
        break;

    case enState_AttackA:
        m_spriteRender.SetMulColor({ 1.0f, 1.0f, 1.0f, 1.0f });
        break;

    case enState_AttackB:
        PlaySe(enSound_BossRage);
        m_spriteRender.SetMulColor({ 1.0f, 0.5f, 0.5f, 1.0f });  // 赤くなる
        break;

    case enState_Dying:
        PlaySe(enSound_BossExplosion);
        PlayBigExplosion();
        AddScore(10000);
        break;
    }
}

この書き方の良いところ

  • ChangeState() を通れば必ず1回だけ呼ばれるので、 書き忘れも二重呼び出しも起きません
  • 「入ったとき」の処理が1か所にまとまるので、読みやすい
  • 状態を追加するとき、OnEnterState に1行足すだけ
この形が、そのまま State パターンになります 「入ったとき（Enter）」「毎フレーム（Update）」 「出るとき（Exit）」の3つを持たせる、というのが LV4-05 State パターンの基本形です。 あなたはもう、その半分を自分で書いています。

08確認

  1. ステートマシンにすると、何が良くなる？
  2. m_stateTimer は何に使う？ いつリセットする？
  3. 登場中に無敵にするには、どこで弾く？
答え
  1. 状態ごとに関数が分かれるので、1つ1つが短くなる。状態が増えても複雑にならない。
  2. 「状態に入ってから何秒たったか」。ChangeState() の中で0に戻す。
  3. TakeDamage() の先頭で、状態を見て return する。
