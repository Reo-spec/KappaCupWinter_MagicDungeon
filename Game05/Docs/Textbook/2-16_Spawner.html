01この章でできるようになること

  • 敵が時間とともに出てくるようにできる
  • 出現パターンをコードの外（ファイル）に出せる
  • 調整のたびにビルドし直さなくて済むようになる

02まずは単純に

一定の間隔で敵を出すだけなら、これで動きます。 

class EnemySpawner : public IGameObject {
public:
    bool Start() override;
    void Update() override;
private:
    float m_timer = 0.0f;
    static const float INTERVAL;
};

const float EnemySpawner::INTERVAL = 1.0f;

void EnemySpawner::Update()
{
    m_timer -= g_gameTime->GetFrameDeltaTime();
    if (m_timer > 0.0f) {
        return;
    }
    m_timer = INTERVAL;

    Enemy* enemy = NewGO<Enemy>(enPriority_Enemy, "enemy");
    float x = (float)(rand() % 1600 - 800);      // -800 〜 800 のどこか
    enemy->SetPosition({ x, 600.0f, 0.0f });     // 画面の上から
}

これで「動くもの」はできます。 まずはここまで作って、遊べる状態にしてください。

03でも、これでは調整できない

実際にゲームを作り始めると、こうなります。

  • 「最初の10秒はもっと少なくしたい」
  • 「30秒で強い敵を出したい」
  • 「左右対称に3体まとめて出したい」

これを if で書いていくと、すぐに読めなくなります。 

// こうなっていく
if (m_time < 10.0f) { ... }
else if (m_time < 20.0f && m_count % 3 == 0) { ... }
else if (m_time < 30.0f) { ... }
// 100行後...
「変わるもの」はコードの外へ 何度も調整する値は、ソースコードに書かないでください。 ビルドに時間がかかるので、1回の調整に何分もかかります。 ファイルに出しておけば、ゲームを起動したまま、または再起動だけで試せます。

04出現表をCSVにする

Assets/data/enemyWave.csv のようなファイルを用意します。 

# 出現時刻(秒), 種類, X座標
1.0, 0, -300
1.0, 0,  300
3.0, 0,    0
5.0, 1, -500
5.0, 1,  500
10.0, 2,   0
struct SpawnData {
    float time;      // 出現時刻
    int   type;      // 敵の種類
    float x;         // X座標
};

class EnemySpawner : public IGameObject {
public:
    bool Start() override;
    void Update() override;
private:
    void LoadWaveData(const char* filePath);
private:
    std::vector<SpawnData> m_waveData;
    int   m_nextIndex = 0;      // 次に出す行
    float m_time = 0.0f;        // ゲーム開始からの秒数
};
void EnemySpawner::LoadWaveData(const char* filePath)
{
    FILE* file = nullptr;
    if (fopen_s(&file, filePath, "r") != 0 || file == nullptr) {
        return;
    }
    char line[256];
    while (fgets(line, sizeof(line), file) != nullptr) {
        if (line[0] == '#' || line[0] == '\n') {
            continue;                     // コメントと空行は読み飛ばす
        }
        SpawnData data;
        if (sscanf_s(line, "%f,%d,%f", &data.time, &data.type, &data.x) == 3) {
            m_waveData.push_back(data);
        }
    }
    fclose(file);
}

void EnemySpawner::Update()
{
    m_time += g_gameTime->GetFrameDeltaTime();

    // 時刻が来た行を、来たぶんだけ出す。
    while (m_nextIndex < (int)m_waveData.size()
        && m_waveData[m_nextIndex].time <= m_time)
    {
        const SpawnData& data = m_waveData[m_nextIndex];

        Enemy* enemy = NewGO<Enemy>(enPriority_Enemy, "enemy");
        enemy->SetType(data.type);
        enemy->SetPosition({ data.x, 600.0f, 0.0f });

        m_nextIndex++;
    }
}
なぜ while なのか 同じ時刻に複数の行があるとき、if だと1体しか出ません。 while にすれば、時刻が来ている行を全部まとめて出せます。 重いフレームで時間が飛んでも、取りこぼしません。

05動かして確かめる

  • CSVに書いた時刻どおりに敵が出る
  • CSVを書き換えて再起動すると、ビルドせずに出方が変わる
  • 同じ時刻の行が、同時にまとめて出る
  • GameObject List で敵の数が増減している

06よくあるエラー

敵が1体も出ない

原因1：ファイルが読めていない。LoadWaveData の fopen_s が失敗しても、このコードは黙って何もしません。
直し方：読めなかったときに OutputDebugStringA で 知らせるようにする。「黙って失敗する」コードは書かないこと。

敵が一気に全部出る

原因：m_nextIndex++ を忘れている。
直し方：while の中で必ず進める。無限ループになります。

CSVの数字がおかしく読まれる

原因：全角のカンマやスペースが混ざっている。
直し方：半角で書く。Excelで編集したなら、CSVとして保存し直す。

演習1（まねる）

CSVから敵を出せるようにする。

演習2（調整する）

CSVだけを書き換えて、1分間遊べる難易度カーブを作る。 C++のコードは一行も変えないこと。

解答例を見る（まず自分でやってから）

正解はありませんが、「難易度カーブ」には定石があります。 

# 時刻, 種類, X座標

# 0〜10秒：操作に慣れてもらう。まばらに、避けやすく。
2.0, 0,    0
4.0, 0, -400
6.0, 0,  400
8.0, 0, -200
8.5, 0,  200

# 10〜30秒：数を増やす。同時に複数。
11.0, 0, -600
11.0, 0,  600
14.0, 0, -300
14.0, 0,    0
14.0, 0,  300
18.0, 1, -500
18.0, 1,  500

# 30〜50秒：硬い敵を混ぜる。密度を上げる。
32.0, 2,    0
34.0, 0, -700
34.0, 0,  700
36.0, 1,    0
...

# 55秒：ボス
55.0, 9,    0

作るときのコツ

  • 最初の10秒は簡単に。いきなり難しいと、遊ぶ人はやめます
  • ときどき「休み」を入れる。ずっと密度が高いと疲れます。 5秒くらい何も出ない時間があると、次の波が引き立ちます
  • 山を作る。だんだん難しく、ではなく「難 → 休み → もっと難」 のリズムにすると飽きません

そして、必ず自分で遊んで直してください。 これを何回繰り返せるかが、ゲームの出来を決めます。 CSVにしたのは、その回数を増やすためです。

演習3（自分で書く）

CSVに「動き方の種類」の列を足して、 まっすぐ来る敵と、左右に揺れながら来る敵を出し分ける。 本文には答えがありません。

解答例を見る（まず自分でやってから） 
# 時刻, 種類, X座標, 動き方
1.0, 0, -300, 0     # 0 = まっすぐ
1.0, 0,  300, 0
5.0, 0, -500, 1     # 1 = 左右に揺れる
5.0, 0,  500, 1
struct SpawnData {
    float time;
    int   type;
    float x;
    int   moveType;      // ★ 追加
};

// 読み込み
if (sscanf_s(line, "%f,%d,%f,%d",
        &data.time, &data.type, &data.x, &data.moveType) == 4) {
    m_waveData.push_back(data);
}

// 出すとき
enemy->SetMoveType(data.moveType);
// Enemy.cpp
void Enemy::Move()
{
    const float dt = g_gameTime->GetFrameDeltaTime();
    m_timer += dt;

    switch (m_moveType) {
    case enMove_Straight:
        m_position.y -= 200.0f * dt;
        break;

    case enMove_Wave:
        m_position.y -= 150.0f * dt;
        m_position.x = m_startX + sinf(m_timer * 3.0f) * 200.0f;
        break;
    }
}

気をつけるところ

  • sscanf_s の戻り値を == 4 に直すのを忘れない。 3 のままだと1行も読めません
  • 揺れる動きは、出現したときのXを m_startX に覚えておいて、 そこからの差で計算します。そうしないと、毎回画面中央を基準に揺れてしまいます
  • switch が増えてきたら、それは LV4-09（Strategyパターン）の出番です。 いまは switch で構いません

08確認

  1. 出現パターンをCSVに出すと、何が良い？
  2. if ではなく while で出すのはなぜ？
  3. ファイルが読めなかったとき、黙って何もしないのはなぜダメ？
答え
  1. ビルドせずに調整できる。調整の回数を何倍もこなせる。
  2. 同じ時刻の行をまとめて出すため。重いフレームでの取りこぼしも防げる。
  3. 原因が分からないまま「なぜか出ない」状態になるから。失敗は必ず知らせる。
