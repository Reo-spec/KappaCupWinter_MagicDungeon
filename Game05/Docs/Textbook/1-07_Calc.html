LV1 入門 ／ 1-07

計算と代入 ― 物を動かす

難易度 ／ 前提 1-06

01この章でできるようになること

  • 変数の値を計算して書き換えられる
  • = は「等しい」ではないと説明できる
  • 整数の割り算の落とし穴を知っている

02= は「代入」

数学では = は「等しい」ですが、 C++では「右のものを、左に入れる」という意味です。 

int hp = 100;      // hp に 100 を入れる
hp = 80;           // hp に 80 を入れる（上書き）
hp = hp - 10;      // hp の中身から10引いて、また hp に入れる → 70

hp = hp - 10; は、数学では「ありえない式」ですが、 C++ではごく普通の書き方です。 右から左へ、値が移動すると考えてください。

03計算の記号

記号意味例
+足すa + b
-引くa - b
*かける（× ではない）a * b
/割る（÷ ではない）a / b
%割った余り7 % 3 は 1

% は意外と便利です。「3回に1回だけ何かする」といった処理に使えます。

04短く書く記号

hp = hp + 10;    →    hp += 10;
hp = hp - 10;    →    hp -= 10;
hp = hp * 2;     →    hp *= 2;
hp = hp / 2;     →    hp /= 2;

count = count + 1;    →    count++;   // 1増やす専用
count = count - 1;    →    count--;   // 1減らす専用

意味はまったく同じです。 短いほうが読みやすいので、こちらを使ってください。

05整数の割り算に注意

1 / 2 は 0 になります int どうしの割り算は、小数点以下が切り捨てられます。 
int a = 1 / 2;              // 0 になる（0.5 ではない）
int b = 7 / 2;              // 3 になる（3.5 ではない）

float c = 1 / 2;            // これも 0.0f になる！
                            // 割り算のあとで float にしても手遅れ

float d = 1.0f / 2.0f;      // 0.5f  ← 正しい

float c = 1 / 2; が 0 になるのが、 いちばん引っかかるところです。 1 / 2 の計算が先に終わってしまい、 その結果（0）を float に入れているからです。

小数で計算したいなら、計算の時点で小数にします。 

float rate = (float)m_hp / (float)m_maxHp;    // HPの割合を出す

06動かしてみる

1-04 でやったことを、変数を使って書き直します。 

// Game.h
private:
    FontRender m_fontRender;
    float m_posX  = 0.0f;
    float m_speed = 3.0f;
    int   m_frameCount = 0;

// Game.cpp
void Game::Update()
{
    m_posX += m_speed;      // 毎フレーム進む
    m_frameCount++;         // 何フレーム目か数える

    wchar_t text[256];
    swprintf_s(text, 256, L"posX=%.1f  frame=%d", m_posX, m_frameCount);
    m_fontRender.SetText(text);
}
  • posX がどんどん増えていく
  • frame は1秒でだいたい60増える
  • m_speed を変えると、増え方が変わる

07演習

演習1（まねる）

上のコードを書いて、数字が増えていくのを確認する。

演習2（計算する）

m_frameCount から「何秒たったか」を計算して表示する。（1秒 = 60フレームとして）

解答例を見る（まず自分でやってから） 
void Game::Update()
{
    m_frameCount++;

    float seconds = m_frameCount / 60.0f;     // ★ 60.0f にする

    wchar_t text[256];
    swprintf_s(text, 256, L"%.1f 秒", seconds);
    m_fontRender.SetText(text);
}
/ 60 と書くと壊れます 
float seconds = m_frameCount / 60;     // ← 整数の割り算になる
m_frameCount は int、60 も int なので、 整数どうしの割り算になり、小数点以下が切り捨てられます。
59フレーム目まで 0、60フレーム目でいきなり 1。 なめらかに増えません。
60.0f と書けば直ります。

これは実際に非常によくやる間違いです。 「なぜか0のまま」「なぜかカクカク増える」ときは、ここを疑ってください。

演習3（使ってみる）

%（余り）を使って、1秒に1回だけ出力ウィンドウにメッセージを出す。

解答例を見る（まず自分でやってから） 
void Game::Update()
{
    m_frameCount++;

    if (m_frameCount % 60 == 0) {       // 60で割った余りが0＝60回に1回
        char text[256];
        sprintf_s(text, "%d 秒経過\n", m_frameCount / 60);
        OutputDebugStringA(text);
    }
}

m_frameCount % 60 は 0, 1, 2, ..., 59, 0, 1, 2, ... と繰り返します。 == 0 になるのは60回に1回だけです。

この書き方は「N回に1回」をやりたいときの定番です。 

if (m_frameCount % 10 == 0) { ... }    // 10回に1回
if (m_frameCount % 2  == 0) { ... }    // 2回に1回（偶数フレーム）
ただし、ゲームでは使いどころに注意 フレーム数で数えると、PCが重いときにタイミングが変わってしまいます。 デバッグ表示なら構いませんが、ゲームの動きに使うのは危険です。 正しいやり方は 2-02 でやります。

08確認

  1. hp = hp - 10; は何をしている？
  2. float x = 1 / 2; の結果は？ なぜ？
  3. count++ と同じ意味の書き方は？
答え
  1. hp の中身から10引いた結果を、また hp に入れている。
  2. 0.0f。1 も 2 も整数なので、 先に整数の割り算（結果 0）が行われるから。
  3. count = count + 1; または count += 1;
