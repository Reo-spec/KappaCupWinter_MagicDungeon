02サンプルを使えるようにする

Sample/ フォルダの中の setup.bat を、 右クリックして「管理者として実行」してください。

これで、それぞれのサンプルからエンジン本体へのショートカットが作られます。 （エンジンのコピーを27個も置かないための仕組みです）

あとは、遊びたいサンプルの Game/Game.sln を開いて F5 を押すだけです。

05サンプルは「あとで戻ってくる場所」です

困ったらサンプルを開く この先、「音を鳴らしたい」「エフェクトを出したい」となったとき、 まず対応するサンプルの Game.cpp を読んでください。 動くコードが目の前にあるのは、とても強い武器です。
また、素材（画像・音・エフェクト）が無いときも、 サンプルのものをコピーして使えます （素材の用意のしかた）。

メモしておくと、あとで効きます。

  • 絵が好きだと思ったら → LV3 表現 に早く進むとよい
  • 仕組みが気になると思ったら → LV4 設計 が向いています
  • 大量のものが動くのが面白いと思ったら → LV5 最適化 です

この教材は LV2 まで終われば、LV3 と LV4 はどちらから始めてもよい 構成になっています。自分が面白いと思った方向から進んでください。

演習3（読んでみる）

Sample_06 の Game.cpp を開いて眺める。いまは意味が分からなくて当然です。それでも、何行くらいか・どんな単語が出てくるかを見てみる。

解答例を見る（まず自分でやってから）

中身はこれだけです。

bool Game::Start()
{
    m_spriteRender.Init("Assets/sprite/windowsSprite.dds", 1280, 720);
    m_spriteRender.SetScale(Vector3(1.0f, 1.0f, 0.0f));
    return true;
}

void Game::Update()
{
    m_spriteRender.Update();
}

void Game::Render(RenderContext& rc)
{
    m_spriteRender.Draw(rc);
}

画像を1枚出すだけなら、これだけで済みます。

いま分からなくていいのは、次のようなことです。

  • Game:: の :: って何？ → 1-12
  • bool って？ → 1-06
  • RenderContext& rc の & は？ → 1-14
  • なぜ Update が勝手に呼ばれるの？ → 1-16

この4つが、LV1 で学ぶことのほぼ全部です。 いまは「そのうち分かる」と思っておいてください。
