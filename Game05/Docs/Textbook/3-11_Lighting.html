023種類のライト

03陰影が付く理由

なぜ、光が当たる面は明るく、そうでない面は暗くなるのでしょうか。

モデルの面には向き（法線）があります。 その向きと、光の向きを比べて、 「どれだけ正面から光を受けているか」を計算しています。 

// 光の向きと、面の向きの内積
float t = dot(normal, -lightDirection);
t = max(t, 0.0f);              // 裏側は 0（真っ暗）

float3 lig = lightColor * t;   // 正面を向いているほど明るい
面と光の関係内積明るさ
真正面から受けている1.0いちばん明るい
斜め45度約 0.7やや暗い
真横0.0真っ暗
裏を向いているマイナス0 に潰す

これが「ランバート拡散反射」と呼ばれる、いちばん基本の計算です。 内積1回。それだけです。

内積は「どれだけ同じ方向を向いているか」 2つの向きが同じなら 1、直角なら 0、逆なら -1。
ライティング以外にも、「敵は自分のほうを向いているか」 「前方にいるか、後方にいるか」の判定に使えます。

04コードから操作する

// ディレクションライト
DirectionalLight& dirLight = g_renderingEngine->GetDirectionLight();
dirLight.SetDirection({ 1.0f, -1.0f, 1.0f });      // 向き
dirLight.SetColor    ({ 1.0f,  1.0f, 1.0f, 1.0f }); // 色

// アンビエントライト
g_renderingEngine->SetAmbient({ 0.3f, 0.3f, 0.3f });
向きは「光が進む方向」です 「光源がある方向」ではありません。 上から照らしたいなら {0, -1, 0}（下向き）です。 ここはよく間違えます。

時間帯で色を変えると、雰囲気が大きく変わります。 

// 夕方
dirLight.SetDirection({ 1.0f, -0.2f, 0.0f });       // ほぼ真横から
dirLight.SetColor({ 1.0f, 0.6f, 0.3f, 1.0f });      // オレンジ
g_renderingEngine->SetAmbient({ 0.25f, 0.15f, 0.2f });

// 夜
dirLight.SetDirection({ 0.2f, -1.0f, 0.3f });
dirLight.SetColor({ 0.3f, 0.35f, 0.6f, 1.0f });     // 青白い
g_renderingEngine->SetAmbient({ 0.1f, 0.1f, 0.18f });

05GUI で探して、コードに写す

いちばん効率がいいやり方です。

  1. F1 → Lighting パネルを開く
  2. スライダーを動かして、いい感じの値を探す
  3. その数字をコードに書き写す

ビルドし直しながら数字を探すより、何十倍も速いです。

06演習

演習1（まねる）

コードからディレクションライトの向きを変え、陰影の付き方を確認する。

演習2（変える）

時間帯（朝・昼・夕・夜）を切り替えられるようにする。キー入力で切り替えて見比べる。

解答例を見る（まず自分でやってから） 
// TimeOfDay.h
enum EnTimeOfDay {
    enMorning, enNoon, enEvening, enNight, enNumTimeOfDay
};

class TimeOfDay : public IGameObject {
public:
    void Update() override;
    void Set(EnTimeOfDay t);
private:
    EnTimeOfDay m_current = enNoon;
};

// TimeOfDay.cpp
void TimeOfDay::Set(EnTimeOfDay t)
{
    m_current = t;
    auto& dir = g_renderingEngine->GetDirectionLight();

    switch (t) {
    case enMorning:
        dir.SetDirection({ -1.0f, -0.3f, 0.2f });
        dir.SetColor({ 1.0f, 0.9f, 0.75f, 1.0f });
        g_renderingEngine->SetAmbient({ 0.3f, 0.3f, 0.32f });
        break;
    case enNoon:
        dir.SetDirection({ 0.2f, -1.0f, 0.3f });
        dir.SetColor({ 1.0f, 1.0f, 1.0f, 1.0f });
        g_renderingEngine->SetAmbient({ 0.35f, 0.35f, 0.35f });
        break;
    case enEvening:
        dir.SetDirection({ 1.0f, -0.2f, 0.0f });
        dir.SetColor({ 1.0f, 0.6f, 0.3f, 1.0f });
        g_renderingEngine->SetAmbient({ 0.25f, 0.15f, 0.2f });
        break;
    case enNight:
        dir.SetDirection({ 0.2f, -1.0f, 0.3f });
        dir.SetColor({ 0.3f, 0.35f, 0.6f, 1.0f });
        g_renderingEngine->SetAmbient({ 0.1f, 0.1f, 0.18f });
        break;
    }
}

void TimeOfDay::Update()
{
    if (g_pad[0]->IsTrigger(enButtonRB)) {
        int next = (m_current + 1) % enNumTimeOfDay;
        Set((EnTimeOfDay)next);
    }
}

見どころ

  • ライトの向きを変えると、影の向きも変わります（3-12）
  • 夜はアンビエントを下げるのがコツ。下げないと夜に見えません
  • 色はディレクションとアンビエントをセットで考える
数字は GUI で探してください 上の値は一例です。F1 の Lighting パネルで 自分のモデルに合う値を探して、書き写すほうが確実です。

演習3（考える）

アンビエントを {0, 0, 0} にすると、どうなる？ なぜそうなるのか、上の説明から説明してみる。

解答例を見る（まず自分でやってから）

起きること

  • 光が当たっていない面が完全な黒になる
  • キャラクターの裏側がまったく見えなくなる
  • 影の中が真っ黒になり、何があるか分からない

なぜか

明るさは ディレクション ＋ アンビエント です。 ディレクションは max(dot(normal, -lightDir), 0) なので、 裏を向いた面では 0 になります。 アンビエントも 0 なら、合計が 0 ―― 真っ黒です。

現実ではそうならない理由

現実では、壁や床で跳ね返った光が裏側にも回り込みます。 これを正しく計算するのは非常に重い（大域照明といいます）ので、 「どこからでも一定量の光が来ることにする」というごまかしが アンビエントライトです。

逆に、上げすぎると「のっぺり」します アンビエントはすべての面に同じだけ足すので、 上げるほど面どうしの明暗差が相対的に小さくなります。

0.2〜0.4 くらいが目安です。 「影がつぶれない、いちばん低い値」を探すとよい絵になります。

07確認

  1. ディレクションライトが持つのは？ 持たないのは？
  2. 陰影は何を計算して求めている？
  3. SetDirection({0,-1,0}) は、どこから照らす？
  4. アンビエントを上げすぎるとどうなる？
答え
  1. 持つのは向きと色。持たないのは位置（と距離による減衰）。
  2. 面の向き（法線）と光の向きの内積。
  3. 真上から。「光が進む方向」なので下向き＝上から。
  4. 明暗差がなくなり、のっぺりする。
