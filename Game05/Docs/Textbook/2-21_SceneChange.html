02シーンとは「まとまり」

タイトル画面とゲーム画面では、出ているものがまったく違います。 「この画面のあいだだけ存在するオブジェクトのまとまり」をシーンと呼びます。

03作り方 ― 親が子を全部持つ

いちばん分かりやすいのは、シーンが自分の中のオブジェクトを覚えておいて、 消えるときに全部片づけるやり方です。 

// GameScene.h
class GameScene : public IGameObject {
public:
    bool Start() override;
    void Update() override;
    ~GameScene();
private:
    GOHandle<Player>       m_player;
    GOHandle<EnemySpawner> m_spawner;
    GOHandle<GameUi>       m_ui;
    SoundSource*           m_bgm = nullptr;
};
bool GameScene::Start()
{
    m_player.Reset(NewGO<Player>(enPriority_Player, "player"));
    m_spawner.Reset(NewGO<EnemySpawner>(enPriority_Enemy, "spawner"));
    m_ui.Reset(NewGO<GameUi>(enPriority_Ui, "gameUi"));

    m_bgm = NewGO<SoundSource>(0);
    m_bgm->Init(enSound_Bgm);
    m_bgm->Play(true);
    return true;
}

GameScene::~GameScene()
{
    // 自分が作ったものは、自分で片づける。
    DeleteGO(m_player.Get());
    DeleteGO(m_spawner.Get());
    DeleteGO(m_ui.Get());
    DeleteGO(m_bgm);

    // 途中で生まれた敵と弾は、名前で探してまとめて消す。
    QueryGOs<Enemy>("enemy",  [](Enemy* e)  { DeleteGO(e); return true; });
    QueryGOs<Bullet>("bullet", [](Bullet* b) { DeleteGO(b); return true; });
}
DeleteGO(nullptr) は安全です エンジンの DeleteGameObject は nullptr を弾いてくれるので、 m_player.Get() が nullptr でも落ちません。 ただし、それに頼りきらず、片づけの順番は自分で把握しておいてください。

04シーンを切り替える

切り替えは「いまのシーンを消して、次のシーンを作る」だけです。 ただし自分の Update() の中で自分を消すので、 return を忘れないでください。 

void GameScene::Update()
{
    if (m_isGameOver) {
        NewGO<ResultScene>(enPriority_Ui, "resultScene");
        DeleteGO(this);
        return;                  // ★
    }
    ...
}
1フレームだけ両方が存在します DeleteGO(this) しても、実際に消えるのは次のフレームです （2-05）。 つまり次のシーンと前のシーンが、1フレームだけ同時に存在します。 新しいシーンの Start() で FindGO するときは、 古いほうを拾ってしまわないよう注意してください。

05もっと簡単なやり方

シーンを分けるのが難しければ、ひとつのクラスの中で状態を持つ だけでも作れます。 

class Game : public IGameObject {
private:
    enum EnScene { enScene_Title, enScene_Game, enScene_Result };
    EnScene m_scene = enScene_Title;
};

void Game::Update()
{
    switch (m_scene) {
    case enScene_Title:  UpdateTitle();  break;
    case enScene_Game:   UpdateGame();   break;
    case enScene_Result: UpdateResult(); break;
    }
}

まずはこれで完成させて構いません。 規模が大きくなると switch が膨らんでつらくなりますが、 その「つらさ」を感じることが LV4-05（Stateパターン）の入り口になります。

06よくあるエラー

タイトルに戻っても敵が飛んでくる

原因：片づけ漏れ。
直し方：GameObject List を開いて、 タイトルに戻ったときに何が残っているかを確認する。 一目で分かります。

シーンを変えるとクラッシュする

原因：消したシーンを、まだ誰かが生ポインタで参照している。
直し方：GOHandle にする（2-09）。

BGMが重なって鳴る

原因：前のシーンのBGMを DeleteGO していない。
直し方：デストラクタで消す（2-19）。

07演習

演習1（まねる）

タイトル → ゲーム → リザルト → タイトル の流れを作る。

演習2（確認する）

シーンを5往復して、GameObject List の数が毎回同じに戻ることを確認する。 増えていたら片づけ漏れです。

解答例を見る（まず自分でやってから）

手順

  1. GameObject List を開き、Group by prio のチェックを外す
  2. タイトル画面での Alive の数をメモする（例：3）
  3. ゲーム → リザルト → タイトル と一周する
  4. タイトルに戻ったとき、Alive がメモした数と同じか確認
  5. これを5回繰り返す

増えていたら、Filter で犯人を探します。

残りがちなもの原因
bulletシーンを抜けるとき、飛んでいた弾を消していない
enemy同上
名前なし（default）BGMの SoundSource、エフェクト
gameUiシーンのデストラクタで消し忘れ

まとめて消すには QueryGOs が便利です。

GameScene::~GameScene()
{
    QueryGOs<Bullet>("bullet", [](Bullet* b) { DeleteGO(b); return true; });
    QueryGOs<Enemy>("enemy",   [](Enemy* e)  { DeleteGO(e); return true; });
}
5回やる理由 1回では気づけない漏れがあります。 毎回1個ずつ増えるようなバグは、5回やってはじめて「増えている」と分かります。 長く遊ぶ人ほど重くなる、という形で出るので、必ず確認してください。

演習3（自分で書く）

シーンが切り替わるときに画面が黒くフェードするようにする。 全画面の黒いスプライトを、αを変えながら重ねると作れます。 本文には答えがありません。

解答例を見る（まず自分でやってから） 
// FadeScreen.h
class FadeScreen : public IGameObject {
public:
    bool Start() override;
    void Update() override;
    void Render(RenderContext& rc) override;

    void StartFadeOut() { m_state = enState_FadeOut; m_timer = 0.0f; }
    void StartFadeIn()  { m_state = enState_FadeIn;  m_timer = 0.0f; }
    bool IsFinished() const { return m_state == enState_Idle; }

private:
    enum EnState { enState_Idle, enState_FadeOut, enState_FadeIn };
    EnState      m_state = enState_Idle;
    float        m_timer = 0.0f;
    float        m_alpha = 0.0f;
    SpriteRender m_sprite;
    static const float FADE_TIME;
};

// FadeScreen.cpp
const float FadeScreen::FADE_TIME = 0.5f;

bool FadeScreen::Start()
{
    // 画面全体を覆う、真っ黒な1枚。
    m_sprite.Init("Assets/sprite/white.dds", 1920.0f, 1080.0f);
    m_sprite.SetPosition({ 0.0f, 0.0f, 0.0f });
    return true;
}

void FadeScreen::Update()
{
    if (m_state == enState_Idle) {
        return;
    }
    m_timer += g_gameTime->GetFrameDeltaTime();
    float rate = min(m_timer / FADE_TIME, 1.0f);

    if (m_state == enState_FadeOut) {
        m_alpha = rate;              // 0 → 1（だんだん暗く）
    }
    else {
        m_alpha = 1.0f - rate;       // 1 → 0（だんだん明るく）
    }

    if (rate >= 1.0f) {
        m_state = enState_Idle;
    }
    m_sprite.SetMulColor({ 0.0f, 0.0f, 0.0f, m_alpha });
    m_sprite.Update();
}

void FadeScreen::Render(RenderContext& rc)
{
    if (m_alpha <= 0.0f) {
        return;                      // 完全に透明なら描かない
    }
    m_sprite.Draw(rc);
}

使いかた

// 優先度は UI よりさらに大きくする（いちばん手前に出したいので）
NewGO<FadeScreen>(enPriority_Fade, "fade");

// シーンを変えたくなったら
void GameScene::Update()
{
    if (m_isGameOver && m_isFading == false) {
        FindGO<FadeScreen>("fade")->StartFadeOut();
        m_isFading = true;
        return;
    }
    if (m_isFading) {
        FadeScreen* fade = FindGO<FadeScreen>("fade");
        if (fade != nullptr && fade->IsFinished()) {
            NewGO<ResultScene>(enPriority_Ui, "resultScene");
            DeleteGO(this);
            return;
        }
    }
}

FadeScreen はシーンより長生きさせてください。 シーンと一緒に消えてしまうと、フェードが途中で切れます。

08確認

  1. シーン遷移でいちばん難しいのは何？
  2. DeleteGO(this) したあと、次のシーンといつまで同時に存在する？
  3. 片づけ漏れは、どこで確認できる？
答え
  1. 切り替えそのものではなく、前のシーンのオブジェクトの片づけ。
  2. 1フレームのあいだ。実際に消えるのは次のフレームの先頭。
  3. GameObject List パネル。シーンを往復して数が戻るか見る。
