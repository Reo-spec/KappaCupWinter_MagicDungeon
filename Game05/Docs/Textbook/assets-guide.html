共通

素材の用意のしかた

画像・音・エフェクトは、この教材には付いていません。 自分で用意してください。その探し方と、置き場所と、 必ず守らなければいけないルールをまとめます。

この教材に素材は入っていません 本文のコードに出てくる player.dds や bgm.wav は、 ファイル名の例であって、実物はありません。 自分で用意しないと、画面には何も出ませんし、音も鳴りません。

01必要になるもの

種類形式置き場所使う章
画像（スプライト）.dds Game/Assets/sprite/ 2-11
音（BGM・効果音）.wav Game/Assets/sound/ 2-19
エフェクト.efk Game/Assets/effect/ 2-20
3Dモデル.tkm Game/Assets/modelData/ LV3

フォルダが無ければ自分で作ってください。 パスは "Assets/sprite/player.dds" のように書きます。 "../" や "C:/..." で書くと、 他のPCに持っていったときに読めなくなります。

02まずはエンジンに入っているもので動かす

素材を集めるのは、思ったより時間がかかります。 先に「動く」ところまで確認してから、素材を探すほうが早いです。

ほしいものどこにあるか
画像Sample/Sample_06/Game/Assets/sprite/
音Sample/Sample_13/Game/Assets/sound/
エフェクトSample/Sample_17/Game/Assets/effect/
3DモデルGameTemplate/Game/Assets/modelData/

これらを自分のプロジェクトの Assets/ にコピーして、まず表示させてみてください。 「出た」ことを確認してから、本番の素材に差し替えるのが安全です。

真っ白な四角でも、ゲームは作れます 絵が用意できないうちは、単色の四角い画像1枚で全部済ませてかまいません。 自機は白、敵は赤、弾は黄色。それで 2-24 の 完成条件は全部満たせます。 絵が無いことを、作らない言い訳にしないでください。

03自分で探す

本番の素材は、次のどれかで用意します。

方法良いところ気をつけること
自分で作る 権利の問題がまったく無い。ポートフォリオでも強い 時間がかかる
フリー素材サイト すぐ手に入る。質も高い 利用規約を必ず読む
学校が用意したもの 使ってよいことがはっきりしている 先生に確認する

探すときのキーワードの例です。サイト名を覚えるより、 規約を読む習慣をつけてください。サイトの条件は変わります。

free game sprites public domain

04ライセンスの確認 ― ここは必ず読む

拾ってきた画像や音を、確認せずに使ってはいけません 学校の課題だから大丈夫、ということはありません。 作品をポートフォリオとして公開したり、就職活動で見せたりするなら、なおさらです。

素材をダウンロードする前に、その素材の規約で次の4つを確認してください。

確認することなぜ
ゲームに使ってよいか 「個人の鑑賞のみ」という素材もある
クレジット表記が必要か 必要なら、ゲーム内かREADMEに必ず書く
改変してよいか 色を変える・切り抜くのも改変にあたることがある
公開・配布してよいか ポートフォリオサイトや動画で公開するなら必要

やってはいけないこと

  • 市販ゲームやアニメの画像・音楽を使う
  • 検索して出てきた画像を、出どころを確かめずに使う
  • 規約を読まずに「フリー素材」と書いてあるだけで使う
  • 友達が持ってきた素材を、出どころを聞かずに使う

やっておくこと

使った素材の一覧を、プロジェクトに残してください。 Game/Assets/CREDITS.txt のようなファイルを作って、こう書いておきます。 

■ 使用素材

[効果音]
shot.wav      : ○○○（サイト名） https://...
                ライセンス: 商用利用可・クレジット表記不要
explosion.wav : 同上

[画像]
player.dds    : 自作
enemy.dds     : △△△（サイト名） https://...
                ライセンス: CC BY 4.0（クレジット表記が必要）

[BGM]
bgm.wav       : □□□（サイト名） https://...
                ライセンス: 商用利用可・クレジット表記必要

あとから「これどこで拾ったっけ」となると、もう調べようがありません。 ダウンロードしたその場で書いてください。1行で済みます。

就職活動で効きます ポートフォリオに CREDITS.txt が入っていると、 「権利のことを分かっている人だ」と伝わります。 逆に、明らかに権利が怪しい素材が入っていると、 作品の出来に関係なく評価が下がります。

05形式を変換する

画像 → .dds

k2Engine が読めるのは .dds です。PNGやJPGはそのままでは読めません。 変換には、Microsoft が配布している DirectXTex の texconv というツールなどを使います。

  • 透明にしたい部分は、αチャンネルを透明にしておく
  • 大きさは2の累乗（64, 128, 256...）にしておくと安全
  • 変換後、必ず一度ゲームに出して確認する

音 → .wav

mp3 や ogg は読めません。音声編集ソフト（Audacityなど）で .wav に変換します。

  • BGMは長いとファイルが大きくなる。ループ前提で30秒〜1分程度にする
  • 効果音は短く。長いと連射したとき重なって聞きづらい
変換前のファイルも残しておく .dds や .wav に変換したあと、 元のPNGや元の音源も別フォルダに残しておいてください。 あとで「もう少し明るくしたい」となったとき、変換後のファイルからでは戻せません。 SourceAssets/ のようなフォルダを作るとよいでしょう。

06チェックリスト

  • 使う素材の規約を全部読んだ
  • クレジット表記が必要なものは、書く場所を決めた
  • CREDITS.txt に、素材の出どころとライセンスを書いた
  • 変換前の元ファイルを残してある
  • パスが "Assets/..." から始まっている（絶対パスでない）
  • 別のPCにコピーしても、画像と音が出る
