022段階で使う

k2Engine のサウンドは、①ファイルを番号に登録する → ②番号を指定して鳴らすという2段階です。 

bool GameScene::Start()
{
    // ① ファイルを番号に登録する（最初に1回だけ）
    g_soundEngine->ResistWaveFileBank(0, "Assets/sound/bgm.wav");
    g_soundEngine->ResistWaveFileBank(1, "Assets/sound/shot.wav");
    g_soundEngine->ResistWaveFileBank(2, "Assets/sound/explosion.wav");

    // ② BGMを鳴らす
    m_bgm = NewGO<SoundSource>(0);
    m_bgm->Init(0);          // 番号0のファイル
    m_bgm->Play(true);       // true = ループする
    return true;
}
読み込めるのは .wav です mp3 や ogg はそのままでは読めません。.wav に変換して Game/Assets/sound/ に置いてください。

03効果音を鳴らす

SoundSource は IGameObject です。 鳴らすたびに NewGO します。 

void Player::Shoot()
{
    ...
    SoundSource* se = NewGO<SoundSource>(0);
    se->Init(1);            // 番号1 = shot.wav
    se->Play(false);        // false = ループしない
}

ループしない音は、鳴り終わると自動で消えます。 DeleteGO を書く必要はありません。 GameObject List で見ていると、鳴っている間だけ増えて、すぐ減るのが分かります。

ループする音は、自分で消す BGMのように Play(true) したものは、自動では消えません。 シーンを抜けるときに、必ず DeleteGO してください。 
GameScene::~GameScene()
{
    DeleteGO(m_bgm);        // 自分が作ったBGMは自分で片づける
}

これが 2-05 で決めた 「作った人が消す」のルールです。

04そのほかの操作

関数説明
Play(bool isLoop)再生。true でループ
Stop()停止
Pause()一時停止
IsPlaying()再生中か
SetVolume(float)音量。1.0 が標準
SetFrequencyRatio(float)再生速度と音の高さ

SetFrequencyRatio を少しランダムにすると、 同じ効果音が連続しても単調に聞こえなくなります。 小さな工夫ですが、効果は大きいです。 

se->SetFrequencyRatio(0.95f + (rand() % 100) * 0.001f);   // 0.95〜1.05

05番号を enum で管理する

Init(1) の 1 が何の音か、あとで分からなくなります。 2-04 の優先度と同じで、名前をつけてください。 

// SoundId.h
enum EnSoundId {
    enSound_Bgm       = 0,
    enSound_Shot      = 1,
    enSound_Explosion = 2,
    enSound_Damage    = 3,
};
se->Init(enSound_Shot);

06よくあるエラー

音が鳴らない

原因1：ResistWaveFileBank していない。
原因2：ファイルのパスが違う。
原因3：Play() を呼んでいない。
原因4：.wav ではない。

連射すると音が途切れる／重くなる

原因：1フレームに何十個も SoundSource を作っている。
直し方：同じ音は1フレームに1個までにする。 （連射音を60個同時に鳴らしても、耳には1個にしか聞こえません）

シーンを変えてもBGMが鳴り続ける

原因：ループ再生した SoundSource を DeleteGO していない。
直し方：作った側のデストラクタで消す。

07演習

演習1（まねる）

BGMを鳴らし、弾を撃つと効果音が出るようにする。

演習2（確認する）

GameObject List を開きながら効果音を鳴らし、 SoundSource が自動で消えることを目で確認する。

解答例を見る（まず自分でやってから）

手順

  1. ゲームを実行して、F1 → GameObject → GameObject List を開く
  2. Filter は空のまま、Group by prio のチェックを外す
  3. 弾を撃つ（効果音を鳴らす）

見えること

  • 音を鳴らした瞬間、Alive が1増える
  • 名前のない行（default）が増える。 これが SoundSource です。NewGO<SoundSource>(0) と 名前を付けずに作っているためです
  • 音が鳴り終わると、勝手に消えて数が戻る
名前を付けておくと見やすくなります NewGO<SoundSource>(0, "se") のように名前を付けておくと、 Filter で se と打って効果音だけを一覧できます。 デバッグしやすさのために名前を付けるのは、よい習慣です。

BGM（Play(true)）のほうは、いつまでも消えません。 それも同じ画面で確認できます。

演習3（自分で書く）

ボスが出てきたらBGMを切り替えるようにする。 前のBGMを止めて消すのを忘れないこと。 本文には答えがありません。

解答例を見る（まず自分でやってから） 
// GameScene.h
private:
    SoundSource* m_bgm = nullptr;

    void ChangeBgm(int soundId);

// GameScene.cpp
void GameScene::ChangeBgm(int soundId)
{
    // 前のBGMを止めて消す。
    if (m_bgm != nullptr) {
        m_bgm->Stop();
        DeleteGO(m_bgm);
        m_bgm = nullptr;        // ★ 忘れない
    }
    // 新しいBGMを鳴らす。
    m_bgm = NewGO<SoundSource>(0, "bgm");
    m_bgm->Init(soundId);
    m_bgm->Play(true);
}

void GameScene::Update()
{
    if (m_isBossAppeared == false && m_time >= BOSS_TIME) {
        m_isBossAppeared = true;
        NewGO<Boss>(enPriority_Enemy, "boss");
        ChangeBgm(enSound_BossBgm);      // ここで切り替え
    }
}

GameScene::~GameScene()
{
    DeleteGO(m_bgm);            // シーンを抜けるときも忘れない
}

気をつけるところ

  • m_bgm = nullptr; を必ず書く。 書かないと、DeleteGO したポインタが残り、 デストラクタでもう一度 DeleteGO してしまいます （2-08 で見た事故です）
  • 気になるなら GOHandle<SoundSource> にすると、 消し忘れても安全になります
もっと良くするなら BGMをすぐ切り替えず、1秒かけて音量を下げてから切り替えると、 ぐっとプロっぽくなります。SetVolume() を毎フレーム減らすだけです。

08確認

  1. サウンドを鳴らすまでの2段階とは？
  2. ループしない効果音は、自分で DeleteGO する必要がある？
  3. BGMは？
答え
  1. ① ResistWaveFileBank で番号に登録 ② SoundSource を NewGO して Init と Play。
  2. 要らない。鳴り終わると自動で消える。
  3. 必要。ループ再生したものは自動では消えない。
