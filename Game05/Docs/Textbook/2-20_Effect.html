02Effekseer とは

Effekseer は、エフェクトを作るための無料ツールです。 プログラムを書かずに、爆発や魔法陣のような演出を作れます。 k2Engine には最初から組み込まれています。

ツール本体は GameTemplate/tools/Effekseer160Win/ にあります。 作ったエフェクトは .efk という拡張子で保存されます。

まずは既成のエフェクトで動かす 自分でエフェクトを作るのは後回しでかまいません。 Sample_17 に入っている .efk をコピーして使ってください。 まず「出る」ところまで確認してから、作り方を覚えるほうが早いです。

03使い方

サウンドと同じく、①番号に登録 → ②番号で再生の2段階です。 

// EffectEmitter を使うときは、このインクルードが必要。
#include "graphics/effect/EffectEmitter.h"

bool GameScene::Start()
{
    // ① 登録する。パスが u"..." なので注意。
    EffectEngine::GetInstance()->ResistEffect(0, u"Assets/effect/explosion.efk");
    return true;
}
// ② 出す。
void Enemy::PlayExplosion()
{
    EffectEmitter* effect = NewGO<EffectEmitter>(enPriority_Effect);
    effect->Init(0);
    effect->SetPosition(m_position);
    effect->SetScale({ 30.0f, 30.0f, 30.0f });
    effect->Play();
}
パスの前に u が付く ResistEffect が受け取るのは char16_t の文字列です。 u"Assets/effect/explosion.efk" のように u を付けてください。付け忘れるとコンパイルエラーになります。

EffectEmitter も IGameObject です。 再生が終わると自動で消えます（サウンドと同じ）。

04大きさに注意

Effekseer のエフェクトは3D空間のサイズで作られています。 2Dゲームの座標（±960など）に対して、そのまま出すと 点にしか見えないか、画面いっぱいになるかのどちらかです。 

effect->SetScale({ 30.0f, 30.0f, 30.0f });   // 数字は実際に見て調整する

この数字は、見ながら決めるしかありません。 2-23 でスライダーにすると、 実行しながら調整できるようになります。

05よくあるエラー

error C2664 : const char* から const char16_t* へ変換できない

原因：パスの前の u を忘れている。
直し方：u"Assets/effect/xxx.efk"

EffectEmitter が未定義

原因：#include "graphics/effect/EffectEmitter.h" がない。
直し方：使う .cpp に書く。 （これはプリコンパイルヘッダに入っていません）

エフェクトが見えない

原因1：スケールが小さすぎる。まず 100.0f くらいで試す。
原因2：Play() を呼んでいない。
原因3：出した瞬間に、出した側が DeleteGO されて 位置がおかしくなっている。

06演習

演習1（まねる）

敵をやられたときに爆発エフェクトを出す。

演習2（調整する）

スケールを変えて、ちょうどよい大きさを見つける。

解答例を見る（まず自分でやってから）

まず 100.0f くらいから始めて、半分・倍で探すのが速いです。

見えかた次にやること
まったく見えない10倍にする（1000.0f）
点にしか見えない5倍にする
画面いっぱい1/5にする
ちょうどよいその値の前後で微調整

スライダーにすると、この作業が一瞬で終わります。 （2-23） 

// デバッグ用のグローバルな値にしておくと、全部の爆発に一度に効く
float g_explosionScale = 30.0f;

DebugGui::RegisterPanel("Game", "Effect", []() {
    ImGui::SliderFloat("explosion scale", &g_explosionScale, 1.0f, 300.0f);
});

// 使うとき
effect->SetScale({ g_explosionScale, g_explosionScale, g_explosionScale });

値が決まったら、コードに書き戻すか、 Assets/settings/ のファイルに保存しておいてください。

演習3（自分で書く）

Effekseer を起動して、自分でエフェクトを1つ作る。 難しければ、サンプルの .efk を開いて色だけ変えるのでも構いません。 本文には答えがありません。

解答例を見る（まず自分でやってから）

まずは既存の .efk を開いて、色だけ変えるところから始めてください。 ゼロから作ると、最初の1個で挫折します。

  1. GameTemplate/tools/Effekseer160Win/ の中の実行ファイルを起動
  2. Sample/Sample_17/Game/Assets/effect/ の .efk を開く
  3. 左のツリーからノードを選び、「色」のタブで色を変える
  4. 再生ボタンで確認
  5. 別名で保存して、自分の Assets/effect/ に置く
  6. ゲームで読み込んで確認

慣れてきたら、こんな順で覚えると作れるようになります

覚える順できること
色・大きさ・寿命既存のエフェクトを自分好みに変える
生成数・速度粒の量と勢いを変える
テクスチャの差し替え見た目を大きく変えられる
ノードの追加複数の要素を組み合わせる（炎＋煙＋光）
エフェクトは、少ない手数で見栄えが変わります 爆発、被弾、弾の軌跡。この3つがあるだけで、 ゲームの印象はまったく違います。 時間をかける価値のあるところです。

07確認

  1. エフェクトのパスに u を付ける理由は？
  2. EffectEmitter は自分で DeleteGO する必要がある？
  3. エフェクトが点にしか見えないときは？
答え
  1. char16_t の文字列リテラルにするため。
  2. 要らない。再生が終わると自動で消える。
  3. SetScale の値を大きくする。3D用のサイズなので、2Dではかなり大きくする必要がある。
